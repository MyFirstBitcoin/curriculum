# My First Bitcoin — Curriculum

This repository contains the **official educational curriculum of My First Bitcoin**.

It is the **single source of truth** for all pedagogical content produced and maintained by My First Bitcoin, including:
- full training programs,
- glossaries and educational resources,
- short-form educational documents (“one-pagers”).

All content is written in **Markdown**, versioned with Git, and designed to be:
- reusable across platforms,
- easy to translate and maintain,
- openly accessible to educators.


## 🎯 Purpose of this repository

The goal of this repository is to:
- centralize My First Bitcoin’s educational content,
- enable continuous improvement and peer review,
- support translations and global adoption,
- serve as a foundation for websites, PDFs, and books.

This repository focuses on **content**, not on presentation or delivery platforms.


## 📚 What you’ll find here

### Programs
Complete, structured educational programs, such as:
- **Bitcoin Diploma**
- **Bitcoin for Organizations**

Each program is organized into chapters and sections and is available in multiple languages.


## 🌍 Languages & translations

- English is currently the **reference language**.
- Other languages mirror the same structure.


## 🔄 Versioning & releases

This repository follows a **continuous update** model.

- Content is updated continuously on `main`.
- Releases represent stable versions of the curriculum used in classes, partnerships, or public distribution.
