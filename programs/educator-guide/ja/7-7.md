# 7 - 日常生活でビットコインを使う

所要時間：90分

核心アイデア：Lightning Networkは、より速く、安価な取引を可能にし、Bitcoinを基盤としたまま日常の支払いをより実用的にします。

#### 学習目標

このレッスンの終了時に、受講者は以下ができるようになります：

* Lightning Networkとは何か、なぜBitcoinの上に構築されたのかを説明する。
* オンチェーン取引とLightning取引を、速度、コスト、セキュリティのトレードオフの観点から比較する。

* Lightning決済が、2人のユーザーが直接チャネルを持っていなくてもネットワークを通じてどのように送金されるかを実演する。
* Lightningを通じて、コーヒー、食料品、店舗での支払い、地域での利用など、日常生活でBitcoinを使う現実的な方法を特定する。
* BTCPay Server、BTCMap、ギフトカードなどのツールが、実際にBitcoinの利用を拡大するのにどのように役立つかを説明する。
* Bitcoinの循環型経済とは何か、Lightningがそれをより実現可能にする理由を説明する。

##### 7.1 Lightning Network（25分）

**Lightning Networkとは**

Lightning Networkは、Bitcoinの上に構築された決済システムで、ユーザーがビットコインを素早く安価に送受信できる仕組みです。多くの小さな支払いをメインのブロックチェーンの外で処理し、最終的な結果だけを後でオンチェーンに記録します。

この章のカフェのツケの例えが分かりやすい説明方法です：

* 毎回オンチェーンで1つずつ支払う代わりに
* 2人がチャネルを開設する
* 取引ごとに残高を更新する
* チャネルを閉じるときに、最終的な残高だけがブロックチェーンに記録される

これにより、Lightningは頻繁な小額決済においてより速く、安価になります。また、Lightning決済はネットワークを経由してルーティングできるため、支払う相手全員と直接チャネルを持つ必要はありません。

**オンチェーン vs ライトニング**

ここで違いをはっきりと示しましょう。

オンチェーントランザクション

* 直接My First Bitcoinのブロックチェーン上で行われます
* 一般的に処理が遅いです
* ブロックへの取り込みと承認に依存します
* より高いセキュリティが期待できます
* 手数料によっては高額になることがあります

ライトニングトランザクション

* My First Bitcoinの上に構築されたセカンドレイヤー上で行われます
* はるかに速く決済されます
* 通常は非常に安価です
* 少額かつ頻繁な支払いに便利です
* オンチェーン決済と比べてトレードオフがあります

主なポイントをシンプルに伝えましょう：オンチェーンは最終決済に強く、ライトニングはスピードと低コストの日常利用に強いです。ここでの比較は特に役立ちます。

##### 7.2 ライトニングウォレットの種類、10分

ライトニングウォレットはMy First Bitcoinウォレットと同じ基本機能（ビットコインの受け取りと送信）を持ちますが、ライトニングネットワーク用に設計されていることを説明しましょう。その後、この章で扱う主なウォレットの違いを説明します：

* セルフカストディアル：ユーザー自身が鍵を管理します
* カストディアル：他者が鍵を管理します

根本的なトレードオフを明確にしましょう：

* カストディアルウォレットは使いやすく便利に感じるかもしれません
* しかし、ユーザーは他者の許可と管理に依存します
* セルフカストディアルウォレットはより高い所有権と主権を与えます

また、この章の推奨としてオープンソースウォレットを選ぶことを強調しましょう。オープンソースツールはコミュニティによってレビュー・改善・検証が可能だからです。

##### 7.3 ビットコインライトニングウォレットのセットアップ、10分

生徒と一緒に基本的なセットアップの流れを確認しましょう：

* ライトニングウォレットをダウンロードする
* 新しいウォレットを作成する
* リカバリーフレーズを書き留める
* 正しい順番で単語を確認する
* ウォレットが対応していれば追加のセキュリティを設定する
* ウォレットの利用を開始する

特にシードフレーズについて明確に説明しましょう：

* これがあればユーザーはアクセスを回復できます
* これを失うと資金へのアクセスも失う可能性があります
* 他人に知られると資金を管理されてしまいます

このセクションでは、オンチェーンの章と同様に責任と安全な取り扱いを強く強調してください。

##### 7.4 ライトニング取引の送受信、17分

**ライトニング取引が実際にどのように動くか**

ルーティングの説明にはマリコ、ジュン、エミの例を使いましょう。マリコはエミと直接チャネルを持っていなくても、ネットワークにつながっているジュンを経由して安全にエミへ支払いを送ることができます。

以下のポイントを明確にしましょう：

* ライトニングの支払いは仲介者を経由して移動できます
* その仲介者が支払いのルートを手助けします
* ルーティングプロセスは銀行や中央集権的な決済業者を信頼することを意味しません
* ネットワークは暗号技術を使い、支払いが正しい受取人に届くようにします

これにより、ライトニングは広いネットワーク構造を通ってもピアツーピアであることが理解できます。必要に応じて、この章ではノード運営者が手数料を得たり、ネットワーク強化に貢献できることも触れていると伝えましょう。

**チャネルへの資金供給とライトニングの繰り返し利用**

ミナの例をさらに説明しましょう：

* ミナはオンチェーンウォレットからライトニングウォレットにビットコインを移動します
* これによって支払いチャネルに資金が供給されます
* 彼女はその後、毎回プロセスを再開することなく、繰り返し支払いを行うことができます。
* チャネルが閉じると、最終的な残高がオンチェーンに戻されて精算されます。

重要な制限事項を明確に伝えましょう：アクティブなチャネルにロックされた資金はLightningで使用されており、同時に別のオンチェーン用途として自由に使うことはできません。これにより、Lightningが強力である一方で、異なる支払い構造を伴うことを生徒が理解しやすくなります。

##### 7.5 ビットコインでコーヒーや食料品を買う（20分）

**日常のユースケース**

仕組みから実生活へと話題を移しましょう。

Lightningが特に役立つ場面を説明しましょう：

* コーヒーを買う
* 食料品
* ショッピング
* 友人への支払い
* 日常の小さな取引

この章のミナの例は、多くの場面でLightningが従来の決済手段よりも優れている理由を示しています：高速、低手数料、国境を越えて利用でき、銀行口座を持たない人でもアクセス可能です。比較表や決済処理の図は、特に従来のカード決済にどれだけ多くの仲介者が存在するかを示すのに役立つ強力な教材です。

**加盟店ツールと現実世界でのビットコイン利用**

次に、Lightningを日常生活でどのように実用的に使えるかを、ビジネスやユーザーの視点から説明しましょう。

この章で紹介されている3つの主要なツールや方法を取り上げましょう：

BTCPay Server

* オープンソースの決済プロセッサー
* 加盟店がビットコインを直接受け取ることを可能にします
* 資金を管理する仲介者がいません
* オンライン・対面ビジネスの支払いに便利です

BTCMap

* ビットコインを受け入れる加盟店やコミュニティを探すのに役立ちます
* 地域で検索できます
* コミュニティによって更新可能です

ギフトカードとバウチャー

* 直接受け入れがまだない場所でビットコインを使うための移行的なツール
* 普及が進むまでの橋渡しとして役立ちます

このセクションは、ビットコインの利用が理論上だけでなく、すでに現実に使えるツールが存在することを生徒に示すため重要です。

**循環型経済と交換手段としてのビットコイン**

メインコンテンツの締めくくりとして、循環型経済とは、参加者同士ができるだけお互いに売買し合うことを目指すコミュニティであると説明しましょう。ビットコインに当てはめると、加盟店、労働者、ユーザーがビットコインで取引し合い、経済的に支え合うことを意味します。

ここでLightningがなぜ重要なのかを明確にしましょう：

* 支払いがほぼ即時に完了します
* 手数料が低いです
* 小額決済が現実的になります
* 地域内の取引が持続しやすくなります

この章では、アルンヘムやビットコインビーチのような例が紹介されており、循環型経済が仮説ではなく、すでに存在し成長し続けていることを示しています。特にビジュアルのタイムラインが役立ちます。

##### 理想的な姿

* 「ビットコインは10分かかり、手数料が2ユーロ」という課題から始め、Lightningをビットコインの上にある高速レーンとして説明し、実際の店舗や送金ルートの事例を使い、オンチェーンとLightningの使い分けを判断するための意思決定ツリーを作成することが重要です。
* 教育者はLightningが実際に解決することに現実的であるべきで、ビットコインが使われている現場のストーリーを共有し、具体的なトレードオフを明確にし、可能性にワクワクしつつも普及については現実的な姿勢を保つべきです。
* 生徒はビットコインが実際に現場で支払いに使われている様子を体験し、支払いにおいてスピードとコストが重要であることを理解し、ビットコインが地域内で循環する経済を想像し、Lightning≠ビットコイン（用途が異なるツール）であることを認識し、ビットコイン決済を基盤とした経済システムに興味を持つようになります。
* 生徒がLightning Networkをビットコインの上にあるレイヤーとして説明でき、ペイメントチャネルやルーティングの基本を理解し、Lightning決済の実例を見て、オンチェーンとLightningを状況ごとに比較でき、循環型経済の概念を理解し、それぞれのアプローチの具体的なトレードオフを認識できれば、学習目標は達成されます。
