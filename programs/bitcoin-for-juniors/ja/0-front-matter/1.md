# はじめに

私たちの子どもたちが受け継ぐ世界は、まさに今、形作られています。お金、情報、そして協力のためのツールは、多くの教育システムが追いつけないほど急速に進化しています。次の世代がその世界に明確さと自信を持って向き合うのか、それとも混乱と依存の中で迎えるのかは、今日私たちが何を教えるかに大きくかかっています。

教育は常に、単なる情報の伝達以上のものでした。その目的は、自ら問い、評価し、自分自身の結論にたどり着ける独立した考え方を育てることです。その力は、今こそこれまで以上に重要です。

My First Bitcoinは、そのような教育を築くために存在します。私たちは、現在の金融システムは壊れており、ビットコインこそがデジタル時代の健全なお金であると信じています。教育はオープンソースであり、金銭的な動機から自由であるべきだと考えます。学ぶ人が自分で考える力を持てるようにすること――何を考えるべきかを教えるのではなく、どう考えるかを支えること――それこそが最も大切な仕事です。

Bitcoin for Juniorsは、子ども向けビットコイン教育の新しい基準を打ち立てます。これは私たちのビットコインディプロマの単なる簡易版ではなく、再構築されたものです。遊び心があり、年齢に合ったインタラクティブな学びを通じて、8歳から12歳の子どもたちは、価値、希少性、交換、公平性、プライバシー、責任といった核心的なアイデアを探求します。これは技術的なコースではなく、特定の信念を推奨するものでもありません。子どもたちが自分で考え、自分なりの結論を導き出すための基礎を提供します。

教育者は、影響を何倍にも広げる存在です。このプログラムは、教師や地域の教育者が、実践的で年齢に合った魅力的な学びを届けるためのツールを提供します。目標はビットコイン信者を増やすことではなく、システムを問い、オープンで分散化された世界に参加できる、より明晰な思考力を持つ人を育てることです。

次の世代は、お金について何を考えるべきかを教えられる必要はありません。自分自身で考え抜くための土台が必要なのです。Bitcoin for Juniorsは、その土台を提供します。
