# 3.0 はじめに

> 人類の歴史は、お金の価値が失われていく歴史です。  
_ミルトン・フリードマン_

前のモジュールでは、お金がどのように進化してきたか、そして私たちの貨幣制度が健全なマネーから不健全なマネーへと移行し、今日の世界を形作ったかを学びました。このモジュールでは、これらの変化がどのようにして現在の法定通貨制度につながったのか、そしてその法定通貨制度がどのように機能しているのかをさらに深く掘り下げていきます。

###### では、私たちが現在使っている法定通貨制度はどのようにして誕生したのでしょうか？

それを理解するためには、アメリカドルについて見てみる必要があります。現在、ドルは世界の主要な基軸通貨として使われており、多くの国が貿易や貯蓄、金融の安定のためにドルに依存しています。そのため、アメリカドルに関する決定は世界中の経済に影響を与えます。

自分の国でお金がどのように機能しているのかを理解するには、現代の法定通貨制度がアメリカでどのように発展したのかを知ることが役立ちます。
