# 3.3 中央銀行デジタル通貨

中央銀行デジタル通貨（CBDC）は、法定通貨の次の段階です。紙幣や硬貨、デジタル決済が組み合わさった従来の形とは異なり、CBDCは政府が発行し中央銀行が管理する、完全にデジタルな法定通貨です。

毎日使っている通貨を想像してください。ただし、物理的な形は一切ありません——ポケットで鳴る硬貨も、折りたたむ紙幣もありません。CBDCの特徴は、政府や中央銀行がこれまでにないほど通貨を管理・監視できる点です。CBDCを使えば、当局は金融取引を詳細に把握できるようになり、お金の流れを追跡・規制・制限することがより容易になります。

政府や中央銀行は、CBDCの形態や供給量を簡単に調整したり、金利を操作したり、金融・財政政策の手段をより正確に実施したりできます。つまり、CBDCは当局が法定通貨をコントロールし管理するための、より効率的な手段を提供します。

CBDCが法定通貨の未来のように見える一方で、現在の世界の金融システムもすでに純粋な法定通貨基準で運用されています。法定通貨はもはや金と結びついておらず、実質的な制約なしに通貨供給量が大きく拡大しています。
