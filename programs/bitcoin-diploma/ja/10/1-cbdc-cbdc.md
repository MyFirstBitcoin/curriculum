# 10.1 中央銀行デジタル通貨（CBDC）とは、中央銀行が発行するデジタル形式のお金です。これは現金（紙幣や硬貨）のデジタル版であり、国家が公式に認めた通貨です。CBDCは、一般の人々や企業が利用できるように設計されており、銀行口座や電子ウォレットを通じて取引や支払いに使うことができます。従来の現金と同じ価値を持ちますが、デジタルで管理されるため、送金や決済がより迅速かつ効率的に行える特徴があります。

中央銀行デジタル通貨（CBDC）は、通常の法定通貨のデジタル版です。CBDCは法定通貨と同じルールに従い、中央当局（政府など）が一方的に供給量を増やすことができ、その過程で人々の購買力が減少します。しかし、CBDCはさらに、政府に世界中の人々がそのお金をどのように使うかを管理するための新しく強力なツールも与えます。

ヒューマン・ライツ・ファウンデーション（HRF）の調査によると、世界のGDPの98％を占める134の国と通貨同盟がCBDCを検討しています。2020年5月にはその数はわずか35でした。現在、66カ国が開発、パイロット、または導入といった先進段階にあります。G20のすべての国がCBDCを検討しており、そのうち19カ国はCBDCの先進段階にあります。


> **Callout**
>
> 自分の国がCBDCを試しているかどうかは、ヒューマン・ライツ・ファウンデーションのCBDCトラッカーで確認できます：[cbdctracker.hrf.org](https://cbdctracker.hrf.org/) または [cbdctracker.org](https://cbdctracker.org/)


では、デジタルであること以外に、CBDCは通常の法定通貨と何が違うのでしょうか？重要なのは、紙幣や硬貨の形の通常の法定通貨とは異なり、CBDCは政府が世界中のすべての取引をデジタルで監視・管理できることです。つまり、政府があなたやあなたのお金の使い方を気に入らなければ、特定の取引を止めたり、あなたの口座全体を凍結したりすることができるのです。

例えば、あなたが助けを必要としている国にいる家族にお金を送りたいと思っても、あなたの国の政府がその国の指導者に反対しているために取引を拒否されるかもしれません。または、あなたがSNSで自由に意見を表明したために、好きなものを買おうとお店に行っても買えない、ということもあり得ます。

現在、流通している法定通貨のほとんどはすでにデジタル化されていますが、その違いは、複数の銀行が自分たちの口座を通じてのみ取引を監視・検閲できる点です。それでも、上記のような検閲の例は多くの国で実際に起こっており、銀行によって実行されるものの、多くの場合は中央政府の指示によるものです。

しかしCBDCは、政府に自国の通貨の使い方に対する大きなコントロール権を与え、個人が自由にお金を使う能力を制限します。CBDCによって、政府が人手を介さずに政策を即座に実行できるようになると主張する人もいます。複数の銀行と調整する代わりに、国内の資金の流れを迅速に追跡し、ブロックすることができるのです。


| CBDC | Bitcoin |
| --- | --- |
| 供給量無制限 | 供給量限定 |
| 中央集権型 | 分散型 |
| 不透明な金融政策 | 明確な金融政策 |
| クローズド＆許可制 | オープン＆許可不要 |
| 没収リスクあり | 没収不可能 |
| プライバシー侵害 | プライバシー重視 |
| 検閲を可能にする | 検閲耐性あり |


CBDCもBitcoinもどちらもデジタルですが、この類似点を除けば、全く異なる哲学を持つ異なる形態のお金であり、異なる結果をもたらします。
