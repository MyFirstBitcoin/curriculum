# 1.0 はじめに

> お金は、人類が発明した中で最も偉大な自由の道具の一つです。  
_フリードリヒ・ハイエク_

My First Bitcoinのビットコイン・ディプロマへようこそ。このモジュールでは、お金が私たちの生活に不可欠である理由という根本的な問いを探ります。お金の本質やさまざまな形態について考察し、その重要性をより深く理解することを目指します。

お金は私たちが毎日使っているものですが、なぜそれが必要なのか、そしてお金とは何なのか、本当に理解しているでしょうか？

* なぜ人々は自分の時間をお金と交換するのでしょうか？
* なぜある人は他の人よりも多くのお金を持っているのでしょうか？
* なぜ国が違えばお金も違うのでしょうか？
* 必要なときにもっとお金を作ればいいのに、なぜそれができないのでしょうか？
