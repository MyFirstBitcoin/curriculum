# 8.0 Panimula

> Ang Bitcoin ay hindi "walang regulasyon;" ito ay nire-regulate ng algorithm sa halip na ng mga burukrasya ng gobyerno. Hindi tiwali._Andreas M. Antonopoulos_

Sa modyul na ito, mas malaliman nating titingnan ang teknikal na bahagi ng Bitcoin. Ipinaliwanag namin sa simpleng paraan ang kriptograpiya na nagpoprotekta sa protocol at kung paano gumagana ang mga transaksyon. Maaaring mukhang teknikal ang ilang konsepto, ngunit huwag mag-alala. Maraming tao ang gumagamit ng internet araw-araw kahit hindi nila lubos na nauunawaan kung paano ito gumagana.

Ang pag-aaral sa teknikal na bahagi ng Bitcoin ay isang mahabang paglalakbay na hindi naman kinakailangan para sa lahat. Habang hinihikayat namin ang patuloy na pagkatuto, ang modyul na ito ay nakatuon sa mga pangunahing kaalaman.

Ang Bitcoin network ay isang pinagsasaluhang talaan ng mga transaksyon na nakaimbak sa maraming computer na tinatawag na nodes. Ang talaang ito, na kilala bilang Bitcoin ledger, ay pseudonymous. Hindi ito naglalaman ng personal na detalye tulad ng pangalan o edad, kundi mga datos ng transaksyon at mga Bitcoin address lamang. Sinusubaybayan ng ledger ang bawat transaksyon mula nang magsimula ang blockchain.

##### Mekaniks ng Bitcoin Protocol

* Proof-of-Work
* Kriptograpikong Time-Stamp
* Pag-aadjust ng Hirap
* Peer-to-Peer na Arkitektura ng Network
* Hash Function at Merkle Tree
* Pampublikong Susing Kriptograpiya
* Pagkalahati ng Block Subsidy
