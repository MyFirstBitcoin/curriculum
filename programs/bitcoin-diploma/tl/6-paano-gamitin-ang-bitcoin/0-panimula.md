# 6.0 Panimula

> Bakit magtitiwala ang kahit sino sa pera ng mga nerd kumpara sa pera ng sentral na bangko? Ang mga nerd ang nagdala sa iyo ng internet. Ang mga bangko ang nagdala sa iyo ng Malaking Depresyon.  
_Satoshi Nakamoto_

Ngayong mas malinaw na natin kung ano ang bitcoin at ang layunin nito, panahon na para matutunan kung paano ito gamitin sa aktwal. Sa module na ito, gagabayan ka namin sa proseso ng pagkuha ng bitcoin, hakbang-hakbang, tatalakayin ang iba't ibang uri ng wallet na maaari mong gamitin, tutulungan kang mag-set up ng sarili mong Bitcoin wallet, at magpapraktis pa tayo ng pagpapadala at pagsubaybay ng Bitcoin transaction sa network. Panahon na para isabuhay ang iyong natutunan!
