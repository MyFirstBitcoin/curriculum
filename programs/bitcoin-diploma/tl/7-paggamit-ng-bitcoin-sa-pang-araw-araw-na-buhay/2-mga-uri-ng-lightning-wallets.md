# 7.2 Mga Uri ng Lightning Wallets

Ang Lightning wallet ay katulad ng Bitcoin wallet dahil pinapayagan ka nitong magpadala at tumanggap ng bitcoin. Ang pangunahing pagkakaiba ay ito ay gumagana sa Lightning Network, isang pangalawang layer na itinayo sa ibabaw ng Bitcoin. Tulad ng mga Bitcoin wallet, ang mga Lightning wallet ay may iba't ibang katangian na dapat isaalang-alang bago pumili.

#### Sariling Pangangalaga vs Pinangangasiwaang Wallet

Maaaring uriin ang mga Lightning wallet sa maraming paraan, ngunit para sa pagiging simple, hinahati namin ito sa dalawang uri: sariling pangangalaga at pinangangasiwaang wallet.  
Ang sariling pangangalagang wallet ay nangangahulugang ikaw ang may kontrol sa iyong mga susi. Ang pinangangasiwaang wallet ay nangangahulugang ibang tao ang may kontrol dito.  
Sa pinangangasiwaang wallet, maaari kang magpadala at tumanggap ng bayad, ngunit umaasa ka sa isang third party at isinusuko mo ang buong kontrol sa iyong pondo para sa kaginhawaan. Maaaring ayos lang ito para sa maliliit na halaga, ngunit inirerekomenda ang paggamit ng sariling pangangalagang wallet kapag naunawaan mo na kung paano ito gumagana. Sa natitirang bahagi ng seksyong ito, magpo-focus lamang tayo sa sariling pangangalagang Lightning wallet.

#### Open Source vs Closed Source

Ang mga Lightning wallet ay maaari ring maging open source o closed source. Mas pinipili ang open-source na wallet dahil ang kanilang code ay pampubliko, maaaring suriin ng kahit sino, at maaaring mapabuti ng komunidad.
