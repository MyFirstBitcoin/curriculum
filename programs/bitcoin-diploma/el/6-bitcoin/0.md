# 6.0 Εισαγωγή

> Γιατί να εμπιστευτεί κανείς τα λεφτά των σπασίκλων αντί για τα λεφτά της κεντρικής τράπεζας; Οι σπασίκλες σας έφεραν το διαδίκτυο. Οι τράπεζες σας έφεραν τη Μεγάλη Ύφεση.  
_Satoshi Nakamoto_

Τώρα που έχουμε μια καλύτερη κατανόηση του τι είναι το bitcoin και ποιος είναι ο σκοπός του, ήρθε η ώρα να μάθουμε πώς να το χρησιμοποιούμε στην πράξη. Σε αυτήν την ενότητα, θα σας καθοδηγήσουμε βήμα-βήμα στη διαδικασία απόκτησης bitcoin, θα εξερευνήσουμε τους διάφορους τύπους πορτοφολιών που υπάρχουν, θα σας βοηθήσουμε να δημιουργήσετε το δικό σας πορτοφόλι Bitcoin και θα εξασκηθούμε ακόμη και στην αποστολή και παρακολούθηση μιας συναλλαγής Bitcoin στο δίκτυο. Ήρθε η ώρα να εφαρμόσετε τη γνώση σας στην πράξη!
