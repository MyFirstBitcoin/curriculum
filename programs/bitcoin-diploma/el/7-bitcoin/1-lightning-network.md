# 7.1 Το Lightning Network

Το Lightning Network είναι ένα σύστημα πληρωμών που επιτρέπει στους χρήστες να στέλνουν και να λαμβάνουν bitcoin γρήγορα και με χαμηλό κόστος. Λειτουργεί δημιουργώντας ένα κοινό πορτοφόλι όπου και τα δύο μέρη αποθηκεύουν κάποια από τα bitcoin τους. Έπειτα, μπορούν να πραγματοποιούν απεριόριστες συναλλαγές μεταξύ τους χωρίς να χρειάζεται να καταγράφεται κάθε μία στην κύρια αλυσίδα μπλοκ. Με αυτόν τον τρόπο, παρακάμπτουν την ανάγκη να επαληθεύεται και να συμπεριλαμβάνεται κάθε συναλλαγή σε ένα μπλοκ, κάτι που κάνει τη διαδικασία και γρήγορη και οικονομική. Τα χαμηλότερα τέλη σημαίνουν ότι το Lightning Network μπορεί να χρησιμοποιηθεί για μικρές πληρωμές που δεν είναι πάντα εφικτές στην αλυσίδα. Όταν τα μέρη αποφασίσουν να τερματίσουν τη συνεργασία τους, μόνο το τελικό υπόλοιπο καταγράφεται στην αλυσίδα μπλοκ.

Φαντάσου μια μέρα δουλεύοντας σε ένα καφέ. Σχεδιάζοντας να μείνεις για ώρα, ανοίγεις μια καρτέλα και προπληρώνεις αντί να πληρώνεις για κάθε παραγγελία ξεχωριστά. Στο τέλος της ημέρας, εσύ και ο ιδιοκτήτης ελέγχετε την καρτέλα για να τακτοποιήσετε το λογαριασμό. Αν η κατάθεσή σου είναι μεγαλύτερη από ό,τι ξόδεψες, παίρνεις πίσω τη διαφορά· αν ξόδεψες περισσότερα, πληρώνεις ό,τι χρωστάς ακόμα.

Αυτό το σύστημα μπορεί να επεκταθεί ώστε να περιλαμβάνει περισσότερους συμμετέχοντες. Για παράδειγμα, σε μία από τις επισκέψεις σου στο καφέ, φέρνεις έναν φίλο που ο μπάρμαν δεν γνωρίζει και δεν μπορεί να του ανοίξει καρτέλα. Προσφέρεις στον φίλο σου να χρησιμοποιήσει τη δική σου καρτέλα για να καλύψει τα έξοδά του και συμφωνείτε ότι θα σου τα επιστρέψει ιδιωτικά. Τώρα φαντάσου χιλιάδες ανθρώπους να κάνουν το ίδιο ταυτόχρονα, επιτρέποντας σε άλλους να χρησιμοποιούν υπάρχουσες καρτέλες για να συνδεθούν με ακόμα περισσότερα άτομα — έτσι λειτουργεί το Lightning Network!

Με το Lightning, μπορείς να κάνεις πληρωμές σε οποιονδήποτε βρίσκεται στο δίκτυο, όχι μόνο στο άτομο με το οποίο μοιράζεσαι απευθείας καρτέλα — αρκεί να βρεθεί μια διαδρομή μεταξύ των δύο μερών. Η πληρωμή σου μπορεί να διασχίσει το δίκτυο μέχρι να φτάσει στον προορισμό της, ακόμα κι αν δεν έχεις ανοιχτό κανάλι απευθείας με τον παραλήπτη.

Ας δούμε τη διαφορά μεταξύ συναλλαγών στην αλυσίδα και εκτός αλυσίδας.

##### Συναλλαγές στην Αλυσίδα

Αυτές είναι συναλλαγές που πραγματοποιούνται απευθείας στην αλυσίδα μπλοκ του Bitcoin. Χρειάζονται περίπου 10 λεπτά για να επιβεβαιωθούν και τα τέλη εξαρτώνται από το μέγεθος της συναλλαγής σε εικονικά bytes. Είναι πιο ασφαλείς αλλά πιο αργές, καθώς απαιτούν τη συναίνεση του δικτύου.

##### Συναλλαγές Lightning Network

Αυτές οι συναλλαγές πραγματοποιούνται σε ένα ξεχωριστό δίκτυο που είναι χτισμένο πάνω στην αλυσίδα μπλοκ του Bitcoin. Ολοκληρώνονται πιο γρήγορα και με χαμηλότερα τέλη. Χρησιμοποιούνται συχνά όταν η ταχύτητα και το κόστος των συναλλαγών είναι πιο σημαντικά. Σε σύγκριση με τις συναλλαγές στην αλυσίδα, είναι λιγότερο ασφαλείς.


|  | Δίκτυο Bitcoin | Lightning Network |
| --- | --- | --- |
| Ορισμός | Ένα αποκεντρωμένο ψηφιακό δίκτυο που χρησιμοποιεί κρυπτογραφία για την ασφάλεια των χρηματοοικονομικών συναλλαγών. | Ένα πρωτόκολλο πληρωμών δεύτερου επιπέδου που λειτουργεί πάνω στην αλυσίδα μπλοκ του Bitcoin, επιτρέποντας ταχύτερες και φθηνότερες συναλλαγές. |
| Πλεονεκτήματα | Αποκεντρωμένο και ασφαλές. Χωρίς αντιστροφές συναλλαγών ή απάτη. Μπορεί να χρησιμοποιηθεί ψευδωνυμικά. Παγκόσμια αποδοχή. | Πιο γρήγορες και φθηνότερες συναλλαγές. Αυξημένη επεκτασιμότητα. Οι συναλλαγές εκτός αλυσίδας δεν επιβαρύνουν την αλυσίδα μπλοκ. |
| Μειονεκτήματα | Αργοί χρόνοι συναλλαγών. Υψηλά τέλη για ορισμένους τύπους συναλλαγών. Πολύπλοκο για αρχάριους. | Μπορεί να απαιτεί εμπιστοσύνη στους διαχειριστές των καναλιών. Απαιτεί συναλλαγή στην αλυσίδα για το άνοιγμα και το κλείσιμο καναλιών. |
