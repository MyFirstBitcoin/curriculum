# 7.5 Αγορά καφέ και ειδών παντοπωλείου με Bitcoin

Έχετε ποτέ αναρωτηθεί αν μπορείτε να χρησιμοποιήσετε bitcoin για να αγοράσετε τον καθημερινό σας καφέ ή να προμηθευτείτε τρόφιμα; Αποδεικνύεται ότι μπορείτε! Υπάρχουν πολλές επιλογές, τόσο διαδικτυακά όσο και με φυσική παρουσία, που σας επιτρέπουν να πληρώσετε με bitcoin. Θα εξερευνήσουμε μερικές από αυτές τις επιλογές, καθώς και τα εργαλεία που θα σας βοηθήσουν να βρείτε τοπικά καταστήματα ώστε να ξοδέψετε bitcoin.

Αν και η πληρωμή με πιστωτική κάρτα ή εφαρμογή μπορεί να φαίνεται εύκολη για τον πελάτη, η επεξεργασία της πληρωμής είναι στην πραγματικότητα πολύπλοκη και περιλαμβάνει πολλούς διαφορετικούς μεσάζοντες.


> **Note – Πώς λειτουργεί η επεξεργασία πληρωμών**
>
> Πελάτης → Έμπορος → Πύλη Πληρωμών → Επεξεργαστής → Δίκτυο Καρτών → Εκδότρια Τράπεζα → Δίκτυο Καρτών → Τράπεζα Εμπόρου → Έμπορος


Κάθε μεσάζοντας χρεώνει μια προμήθεια, οπότε, ενώ μπορεί να φαίνεται εύκολο, γρήγορο και φθηνό, αυτά τα κόστη μπορούν να αυξηθούν γρήγορα για έναν μικρό επιχειρηματία, συχνά ξεπερνώντας το 3% της τιμής. Και χωρίς να υπολογίσουμε τα έξοδα μετατροπής συναλλάγματος!

##### Προμήθειες Επεξεργασίας Πιστωτικών Καρτών


| Ο πελάτης πληρώνει | Εκδότρια Τράπεζα | Επεξεργαστές Δικτύου Καρτών | Επεξεργαστές Πληρωμών | Πηγαίνει στον έμπορο |
| --- | --- | --- | --- | --- |
| 100 | -1,75 | -0,14 | -0,30 | 97,81 |


Με το Bitcoin και το Lightning Network, οι επιχειρήσεις μπορούν να λαμβάνουν άμεσες πληρωμές από όλο τον κόσμο μέσω ενός ανοιχτού, ασφαλούς, εγγενούς στο διαδίκτυο, χωρίς σύνορα και ανθεκτικού στη λογοκρισία νομισματικού συστήματος.

#### Διαδικτυακά

**BTCPay Server** είναι ένας ανοιχτού κώδικα επεξεργαστής πληρωμών που επιτρέπει στους εμπόρους να δέχονται πληρωμές σε bitcoin με ελάχιστες τεχνικές γνώσεις. Είναι εντελώς δωρεάν και δεν χρεώνει καμία προμήθεια. Οι διαδικτυακές επιχειρήσεις μπορούν να ενσωματώσουν το BTCPay Server εύκολα προσθέτοντας το plugin BTCPay στην ιστοσελίδα τους. Επειδή το BTCPay Server είναι ένα έργο ανοιχτού κώδικα και όχι εταιρεία, μπορείτε να συνεισφέρετε στο έργο μόλις μάθετε περισσότερα για αυτό και τον προγραμματισμό υπολογιστών. Δείτε το [BTCPayServer.org](https://btcpayserver.org/) για περισσότερες πληροφορίες σχετικά με το πώς να χρησιμοποιήσετε αυτό το σύστημα πληρωμών για τη φυσική ή διαδικτυακή σας επιχείρηση.

##### BTCPay Server: Πώς διαφέρει;

* **Δωρεάν και ανοιχτού κώδικα**: Φτιαγμένο από ελεύθερους για ελεύθερους. Άδεια MIT. Χωρίς κόστη συναλλαγών, συνδρομών ή επεξεργασίας. Πλήρως ανοιχτού κώδικα. Οι πληρωμές είναι άμεσες, από άτομο σε άτομο.
* **Αποκεντρωμένο**: Ο καθένας μπορεί να εγκαταστήσει έναν server. Γίνετε ο ίδιος επεξεργαστής πληρωμών και λάβετε πληρωμές απευθείας στο πορτοφόλι σας. Βοηθήστε τους φίλους ή την κοινότητά σας και επεξεργαστείτε πληρωμές για αυτούς. Απεριόριστος αριθμός καταστημάτων μπορεί να συνδεθεί σε έναν μόνο BTCPay Server.
* **Ιδιωτικό, χωρίς μεσάζοντες**: Οι αξιόπιστοι τρίτοι είναι τρύπες ασφαλείας. Το BTCPay τους εξαλείφει. Οι πληρωμές είναι P2P, άμεσες. Τα δεδομένα δεν κοινοποιούνται. Δεν υπάρχει KYC/AML.
* **Ασφαλές**: Το ιδιωτικό σας κλειδί δεν απαιτείται ποτέ. Μη θεματοφυλακτικό. Το BTCPay χρειάζεται μόνο xpubkeys (δημόσιο κλειδί) για να δημιουργεί τιμολόγια. Ο κώδικας είναι ανοιχτός και μπορεί να ελεγχθεί από ελεγκτές ασφαλείας και προγραμματιστές.
* **Ανθεκτικό στη λογοκρισία**: Δεν υπάρχει κεντρικό σημείο αποτυχίας. Κανείς δεν το ελέγχει εκτός από τον χρήστη που το τρέχει. Μπορείτε να το τρέξετε στο δικό σας υλικό.

#### Με Φυσική Παρουσία

Τα φυσικά καταστήματα μπορούν επίσης να χρησιμοποιήσουν το BTCPay Server για να δέχονται πληρωμές ή απλά να κατεβάσουν ένα πορτοφόλι Bitcoin και να δέχονται πληρωμές απευθείας από το κινητό τους.

Για να βρείτε έναν έμπορο που δέχεται bitcoin στην περιοχή σας, πηγαίνετε στο [BTCMap.org](https://btcmap.org) και αναζητήστε την περιοχή σας. Το BTCMap.org είναι ένας ανοιχτού κώδικα χάρτης όπου οι έμποροι που δέχονται Bitcoin μπορούν να καταχωρήσουν τις επιχειρήσεις τους. Επιπλέον, οι χρήστες μπορούν επίσης να προσθέσουν νέους εμπόρους και ακόμη και να ενημερώσουν τον χάρτη για να διασφαλίσουν ότι οι καταχωρημένοι έμποροι συνεχίζουν να δέχονται bitcoin. Είναι ένα ισχυρό εργαλείο για όσους θέλουν να ξοδέψουν τα bitcoin τους.

#### Μεταβατικά Εργαλεία: Κουπόνια, Δωροκάρτες και Κάρτες Πληρωμών

Για να αγοράσετε προϊόντα ή υπηρεσίες από επιχειρήσεις που δεν δέχονται ακόμη bitcoin, υπάρχει ένα ενδιάμεσο εργαλείο που μπορείτε να χρησιμοποιήσετε: δωροκάρτες.

Ορισμένες επιχειρήσεις εξειδικεύονται στην αγορά και πώληση δωροκαρτών με αντάλλαγμα bitcoin. Αυτό σημαίνει ότι μπορείτε να αποκτήσετε μια δωροκάρτα για το κατάστημα που θέλετε να ψωνίσετε με αντάλλαγμα bitcoin και στη συνέχεια να ξοδέψετε τη δωροκάρτα απευθείας στο κατάστημα. Αεροπορικά εισιτήρια, ξενοδοχεία, παιχνίδια, κάρτες SIM… μπορείτε να αγοράσετε σχεδόν τα πάντα με bitcoin και δωροκάρτες!

#### Κυκλικές Οικονομίες

![ ](https://cdn.sanity.io/images/vje9ehw2/staging/b7074d4c1f4ba151124ba01f31db4eba6edac85e-190x58.svg)

Μια **κυκλική οικονομία** αποτελείται από συμμετέχοντες που αποφασίζουν να στηρίξουν ο ένας τον άλλον προσπαθώντας να αγοράζουν και να πουλούν μεταξύ τους όσο το δυνατόν περισσότερο. Για παράδειγμα, μια κοινότητα αγροτών που ανταλλάσσουν τα προϊόντα τους αντί να πηγαίνουν στο σούπερ μάρκετ.

Όταν εφαρμόζεται στο Bitcoin, μια κυκλική οικονομία χτίζεται στηρίζοντας τοπικούς εμπόρους και επαγγελματίες που δέχονται bitcoin, ώστε όλοι οι συμμετέχοντες να ευημερούν μαζί χάρη στις ανώτερες ιδιότητες του Bitcoin.


> **Note**
>
> Το Lightning Network επιτρέπει στις κυκλικές οικονομίες του Bitcoin να εμφανίζονται και να ευδοκιμούν σε όλο τον κόσμο χάρη στις σχεδόν άμεσες και χαμηλού κόστους συναλλαγές Bitcoin.


Η πρώτη κυκλική οικονομία Bitcoin που δημιουργήθηκε βρίσκεται στο Άρνεμ, Ολλανδία. Δημιουργήθηκε πολύ πριν υπάρξει το Lightning Network — αλλά τότε, τα τέλη στο blockchain ήταν πολύ χαμηλά!

Η δεύτερη ήταν το Bitcoin Beach, που βρίσκεται στο El Zonte, Ελ Σαλβαδόρ. Ήταν η πρώτη που αξιοποίησε τη δύναμη του Lightning Network για να προσφέρει στην κοινότητα, που ήταν κυρίως χωρίς πρόσβαση σε τράπεζες, άμεσες ψηφιακές πληρωμές απευθείας από τα κινητά τους!

Σήμερα, εκατοντάδες κυκλικές οικονομίες δημιουργούνται σε όλο τον κόσμο, με τη δύναμη του Bitcoin, του Lightning Network και των εκπαιδευτικών πόρων.

Στο [BTCMap.org](https://btcmap.org/communities), μπορείτε επίσης να αναζητήσετε κοινότητες Bitcoin όπου θα γνωρίσετε άλλους χρήστες Bitcoin και θα βρείτε επιχειρήσεις που δέχονται Bitcoin. Μερικοί από τους δασκάλους και τους μαθητές μας έχουν προσθέσει επιχειρήσεις και κυκλικές οικονομίες στο BTCmap.org — και όταν είστε έτοιμοι, μπορείτε κι εσείς!
