# 7.2 Τύποι Lightning Πορτοφολιών

Ένα Lightning πορτοφόλι είναι παρόμοιο με ένα Bitcoin πορτοφόλι, καθώς σου επιτρέπει να στέλνεις και να λαμβάνεις bitcoin. Η βασική διαφορά είναι ότι λειτουργεί πάνω στο Lightning Network, ένα δεύτερο επίπεδο που έχει χτιστεί πάνω από το Bitcoin. Όπως και τα Bitcoin πορτοφόλια, τα Lightning πορτοφόλια έχουν διαφορετικά χαρακτηριστικά που πρέπει να λάβεις υπόψη πριν επιλέξεις κάποιο.

#### Αυτο-θεματοφυλακή vs Θεματοφυλακή

Τα Lightning πορτοφόλια μπορούν να ταξινομηθούν με πολλούς τρόπους, αλλά για απλότητα, τα χωρίζουμε σε δύο τύπους: αυτο-θεματοφυλακής και θεματοφυλακής.  
Ένα πορτοφόλι αυτο-θεματοφυλακής σημαίνει ότι εσύ ελέγχεις τα κλειδιά σου. Ένα πορτοφόλι θεματοφυλακής σημαίνει ότι κάποιος άλλος τα ελέγχει.  
Με ένα πορτοφόλι θεματοφυλακής, μπορείς να στέλνεις και να λαμβάνεις πληρωμές, αλλά βασίζεσαι σε τρίτο μέρος και παραχωρείς τον πλήρη έλεγχο των χρημάτων σου για λόγους ευκολίας. Αυτό μπορεί να είναι εντάξει για μικρά ποσά, αλλά συνιστάται να χρησιμοποιείς πορτοφόλι αυτο-θεματοφυλακής μόλις κατανοήσεις πώς λειτουργεί. Για το υπόλοιπο αυτής της ενότητας, θα επικεντρωθούμε μόνο σε Lightning πορτοφόλια αυτο-θεματοφυλακής.

#### Ανοιχτού Κώδικα vs Κλειστού Κώδικα

Τα Lightning πορτοφόλια μπορούν επίσης να είναι ανοιχτού ή κλειστού κώδικα. Τα πορτοφόλια ανοιχτού κώδικα προτιμώνται επειδή ο κώδικάς τους είναι δημόσιος, μπορεί να ελεγχθεί από οποιονδήποτε και να βελτιωθεί από την κοινότητα.
