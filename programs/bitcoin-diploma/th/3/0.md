# 3.0 บทนำ

> ประวัติศาสตร์ของมนุษยชาติคือประวัติศาสตร์ของเงินที่สูญเสียมูลค่า  
_Milton Friedman_

เราได้เห็นในโมดูลก่อนหน้านี้ว่าเงินวิวัฒนาการมาอย่างไรตามกาลเวลา และระบบการเงินของเราเปลี่ยนจากเงินที่มีเสถียรภาพไปสู่เงินที่ไม่มีเสถียรภาพอย่างไร ซึ่งได้หล่อหลอมโลกที่เราอาศัยอยู่ในปัจจุบัน โมดูลนี้จะเจาะลึกลงไปอีกว่าพัฒนาการเหล่านี้นำไปสู่ระบบเงินเฟียตในปัจจุบันได้อย่างไร และระบบเงินเฟียตนี้ทำงานอย่างไร

###### แล้วระบบเงินเฟียตที่เราใช้กันอยู่ทุกวันนี้เกิดขึ้นมาได้อย่างไร?

เพื่อจะเข้าใจเรื่องนี้ เราต้องมองไปที่ดอลลาร์สหรัฐ ทุกวันนี้ ดอลลาร์ถือเป็นสกุลเงินสำรองหลักของโลก หมายความว่าหลายประเทศพึ่งพาดอลลาร์ในการค้าขาย การออม และเสถียรภาพทางการเงิน ด้วยเหตุนี้ การตัดสินใจเกี่ยวกับดอลลาร์สหรัฐจึงส่งผลกระทบต่อเศรษฐกิจทั่วโลก

เพื่อจะเข้าใจว่าเงินทำงานอย่างไรในประเทศของคุณ การเข้าใจว่าระบบเงินเฟียตสมัยใหม่พัฒนาขึ้นในสหรัฐอเมริกาอย่างไรจะช่วยให้เห็นภาพชัดเจนขึ้น
