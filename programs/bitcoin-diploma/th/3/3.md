# 3.3 สกุลเงินดิจิทัลของธนาคารกลาง

สกุลเงินดิจิทัลของธนาคารกลาง (CBDCs) คือก้าวถัดไปของเงินตราแบบเฟียต แทนที่จะเป็นการผสมผสานระหว่างธนบัตร เหรียญ และการชำระเงินแบบดิจิทัล CBDCs เป็นรูปแบบดิจิทัลเต็มรูปแบบของเงินเฟียตที่ออกโดยรัฐบาลและควบคุมโดยธนาคารกลาง

ลองจินตนาการถึงสกุลเงินที่คุณใช้ในชีวิตประจำวัน แต่ไม่มีตัวตนทางกายภาพเลย — ไม่มีเหรียญให้กระทบกันในกระเป๋า หรือธนบัตรให้พับ สิ่งที่ทำให้ CBDCs แตกต่างคือระดับการควบคุมและการตรวจสอบที่สูงขึ้นซึ่งรัฐบาลและธนาคารกลางสามารถทำได้ ด้วย CBDCs หน่วยงานต่าง ๆ จะสามารถมองเห็นธุรกรรมทางการเงินได้อย่างที่ไม่เคยมีมาก่อน ทำให้พวกเขาติดตาม ควบคุม และจำกัดการไหลเวียนของเงินได้ง่ายขึ้น

รัฐบาลและธนาคารกลางสามารถปรับเปลี่ยนรูปแบบและปริมาณของ CBDCs ได้อย่างง่ายดาย ควบคุมอัตราดอกเบี้ย และใช้เครื่องมือทางนโยบายการเงินและการคลังได้อย่างแม่นยำยิ่งขึ้น กล่าวโดยสรุป CBDCs ช่วยให้หน่วยงานต่าง ๆ มีวิธีที่มีประสิทธิภาพมากขึ้นในการกำหนดและบริหารจัดการเงินเฟียตของตน

แม้ว่า CBDCs ดูเหมือนจะเป็นอนาคตของเงินเฟียต แต่ระบบการเงินในปัจจุบันของโลกก็ได้ดำเนินการบนมาตรฐานเฟียตอย่างแท้จริงอยู่แล้ว สกุลเงินเฟียตไม่ได้ผูกกับทองคำอีกต่อไป ส่งผลให้ปริมาณเงินขยายตัวอย่างมากโดยไม่มีข้อจำกัดที่แท้จริง
