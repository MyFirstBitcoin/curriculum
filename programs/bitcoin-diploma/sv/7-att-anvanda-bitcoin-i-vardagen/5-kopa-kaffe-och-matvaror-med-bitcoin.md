# 7.5 Köpa kaffe och matvaror med Bitcoin

Har du någonsin undrat om du kan använda bitcoin för att köpa din dagliga kopp kaffe eller fylla på med matvaror? Det visar sig att du kan! Det finns många alternativ, både online och i butik, där du kan betala med bitcoin. Vi kommer att utforska några av dessa alternativ samt verktyg som hjälper dig att hitta lokala butiker så att du kan spendera bitcoin.

Även om det kan verka enkelt att betala med kreditkort eller en app för den som betalar, är själva betalningsprocessen faktiskt mycket komplex och involverar många olika parter.


> **Light – Hur betalningshantering fungerar**
>
> Kund → Handlare → Betalningsgateway → Processor → Kortnätverk → Utfärdande bank → Kortnätverk → Handelsbank → Handlare


Varje mellanhand tar ut en avgift, så även om det kan verka enkelt, snabbt och billigt, kan dessa kostnader snabbt bli höga för en småföretagare, ofta över 3 % av priset. Och då har vi inte ens nämnt valutaväxlingsavgifter!

Med Bitcoin och Lightning-nätverket kan företag ta emot omedelbara betalningar från hela världen via ett öppet, säkert, internetbaserat, gränslöst och censurresistent monetärt system.

#### Online

**BTCPay Server** är en öppen källkods-betalningslösning som gör det möjligt för handlare att ta emot betalningar i bitcoin med liten teknisk kunskap. Det är helt gratis och tar ingen provision. Nätbutiker kan integrera BTCPay Server smidigt genom att lägga till BTCPay-pluginet på sin webbplats. Eftersom BTCPay Server är ett öppen källkodsprojekt, inte ett företag, kan du bidra till projektet när du lärt dig mer om det och om programmering. Kolla in [BTCPayServer.org](https://btcpayserver.org/) för mer information om hur du använder detta betalningssystem för din fysiska eller nätbaserade verksamhet.

##### BTCPay Server: Hur skiljer det sig?

* **Gratis och öppen källkod**: Gjord fri till fri. MIT-licens. Inga transaktions-, abonnemangs- eller behandlingskostnader. Helt öppen källkod. Betalningar är direkta, person till person.
* **Decentraliserad**: Vem som helst kan sätta upp en server. Bli din egen betalningsprocessor och ta emot betalningar direkt till din plånbok. Hjälp dina vänner eller din gemenskap och behandla betalningar åt dem. Ett obegränsat antal butiker kan kopplas till en enda BTCPay Server.
* **Privat, ingen mellanhand**: Betrodda tredje parter är säkerhetshål. BTCPay eliminerar dem. Betalningar är P2P, direkta. Data delas inte. Det finns ingen KYC/AML.
* **Säker**: Din privata nyckel krävs aldrig. Icke-förvarande. BTCPay behöver bara xpub-nycklar (publik nyckel) för att skapa fakturor. Koden är öppen källkod och kan granskas av säkerhetsgranskare och utvecklare.
* **Censurresistent**: Ingen central felpunkt. Ingen kontrollerar det förutom användaren som kör det. Du kan köra det på din egen hårdvara.

#### Personligen

Fysiska butiker kan också använda BTCPay Server för att ta emot betalningar, eller så kan de helt enkelt ladda ner en Bitcoin-plånbok och ta emot betalningar direkt från sin telefon.

För att hitta en handlare som accepterar bitcoin i ditt område, gå till [BTCMap.org](https://btcmap.org) och sök efter din region. BTCMap.org är en öppen källkarta där handlare som accepterar Bitcoin kan lista sina verksamheter. Dessutom kan användare lägga till nya handlare och till och med uppdatera kartan för att säkerställa att de listade handlarna fortfarande accepterar bitcoin. Det är ett kraftfullt verktyg för dig som vill spendera dina bitcoin.

#### Övergångsverktyg: Värdebevis, presentkort och betalkort

För att köpa produkter eller tjänster från företag som ännu inte accepterar bitcoin finns det ett mellanliggande verktyg du kan använda: presentkort.

Vissa företag fokuserar på att köpa och sälja presentkort i utbyte mot bitcoin. Det betyder att du kan skaffa ett presentkort till den butik du vill handla i i utbyte mot bitcoin, och sedan använda presentkortet direkt i butiken. Flygbiljetter, hotell, spel, SIM-kort… du kan köpa nästan vad som helst med bitcoin och presentkort!

#### Cirkulära ekonomier

![ ](https://cdn.sanity.io/images/vje9ehw2/staging/b7074d4c1f4ba151124ba01f31db4eba6edac85e-190x58.svg)

En **cirkulär ekonomi** består av deltagare som bestämmer sig för att stötta varandra genom att försöka köpa av och sälja till varandra så mycket som möjligt. Till exempel en gemenskap av bönder som byter sina produkter med varandra istället för att gå till stormarknaden.

När det gäller Bitcoin byggs en cirkulär ekonomi upp genom att stötta lokala handlare och yrkesskickliga arbetare som accepterar bitcoin, så att alla deltagare kan blomstra tillsammans tack vare Bitcoins överlägsna egenskaper.


> **Light**
>
> Lightning-nätverket gör det möjligt för Bitcoin-cirkulära ekonomier att uppstå och blomstra över hela världen tack vare nästan omedelbara och låga transaktionsavgifter.


Den första Bitcoin-cirkulära ekonomin som någonsin skapats finns i Arnhem, Nederländerna. Den skapades långt innan Lightning-nätverket existerade — men då var avgifterna på blockkedjan väldigt låga!

Den andra var Bitcoin Beach, belägen i El Zonte, El Salvador. Det var den första som utnyttjade kraften i Lightning-nätverket för att ge samhället, som till största delen saknade banktjänster, omedelbara digitala betalningar direkt med sina smartphones!

Idag skapas hundratals cirkulära ekonomier över hela världen, drivna av Bitcoin, Lightning-nätverket och utbildningsresurser.

På [BTCMap.org](https://btcmap.org/communities), kan du också leta efter Bitcoin-gemenskaper där du kommer att träffa andra Bitcoin-användare och hitta företag som accepterar Bitcoin. Några av våra lärare och elever har faktiskt lagt till företag och cirkulära ekonomier på BTCmap.org — och när du är redo kan du också göra det!
