# 3.0 Introduktion

> Mänsklighetens historia är historien om pengar som förlorar sitt värde.  
_Milton Friedman_

Vi såg i föregående modul hur pengar har utvecklats över tid och hur vårt monetära system gick från sund till osund ekonomi, vilket har format den värld vi lever i idag. Den här modulen går djupare in på hur dessa utvecklingar ledde till dagens fiat-system och hur det systemet fungerar.

###### Så hur uppstod det fiat-system vi använder idag?

För att förstå det måste vi titta på den amerikanska dollarn. Idag fungerar dollarn som världens främsta reservvaluta, vilket innebär att många länder förlitar sig på den för handel, sparande och finansiell stabilitet. Därför påverkar beslut om den amerikanska dollarn ekonomier över hela världen.

För att förstå hur pengar fungerar i ditt land är det bra att förstå hur det moderna fiat-systemet utvecklades i USA.
