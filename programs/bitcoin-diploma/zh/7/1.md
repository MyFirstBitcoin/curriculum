# 7.1 闪电网络

闪电网络是一种支付系统，允许用户快速且低成本地发送和接收比特币。它的工作原理是双方建立一个共享钱包，并各自存入一些比特币。之后，他们可以在彼此之间进行无限次交易，而无需每一笔都记录在主区块链上。这样一来，就无需验证和将每一笔交易都包含进区块，从而使整个过程既快速又经济。较低的手续费意味着闪电网络可以用于链上不总是可行的小额支付。当双方决定结束合作时，只有最终的余额会被记录在区块链上。

想象你在咖啡馆工作一天。打算待上一会儿，你开了一个账单并预付，而不是每次点单都付款。一天结束时，你和店主一起核对账单结算。如果你的押金多于消费，你会拿回差额；如果消费超出押金，你则补齐剩余款项。

这种方式可以扩展到更多参与者。例如，你某次去咖啡馆时带了一位酒保不认识、无法开账单的朋友。你把自己的账单借给朋友支付消费，并约定他们私下还你。现在想象成千上万的人同时这样做，让其他人也能通过现有账单与更多人建立联系——这就是闪电网络的运作方式！

通过闪电网络，你可以向网络上的任何人付款，而不仅限于与你直接开账单的人——只要能找到双方之间的路径。你的付款可以在网络中跳转，直到到达收款方，即使你与对方没有直接的通道。

让我们来看看链上交易和链下交易的区别。

##### 链上交易

这些交易直接发生在比特币区块链上。确认大约需要10分钟，手续费取决于交易的虚拟字节大小。它们更安全，但速度较慢，因为需要全网共识。

##### 闪电网络交易

这些交易发生在建立在比特币区块链之上的独立网络中。结算速度更快，手续费更低。通常用于对交易速度和成本有更高要求的场景。与链上交易相比，安全性略低。


|  | 比特币网络 | 闪电网络 |
| --- | --- | --- |
| 定义 | 一个去中心化的数字网络，利用加密技术保障金融交易的安全。 | 运行在比特币区块链之上的第二层支付协议，实现更快、更便宜的交易。 |
| 优点 | 去中心化且安全。无退单或欺诈风险。可伪匿名使用。全球接受度高。 | 交易更快更便宜。提升可扩展性。链下交易不会堵塞区块链。 |
| 缺点 | 交易速度较慢。某些类型的交易手续费较高。对初学者来说较为复杂。 | 可能需要信任通道运营者。开通和关闭通道需要链上交易。 |
