# 7.4 发送和接收闪电网络交易

使用闪电钱包，使用比特币变得快速、便宜且隐私，令两个人之间的交易变得轻松。你可以快速地用比特币进行日常消费，比如买咖啡或购物。

让我们来看几个闪电网络实际应用的例子。

###### 例子 1

Marcia 和 Eve 各有 5 个单位的货币。Marcia 想要给 Eve 转账 2 个单位。支付通过 Jeff 传递，他帮助支付在闪电网络中转发。支付完成后，Eve 有 7 个单位，Marcia 剩下 3 个单位。

Jeff 帮助路由支付，但他无法窃取资金。闪电网络使用密码学确保只有指定的收款人才能收到款项。Jeff 只是帮助支付在网络中传递。

这展示了闪电网络的一个关键优势：人们可以在无需信任银行等中介的情况下快速发送支付。

像 Jeff 这样的节点运营者也可以通过帮助路由支付赚取少量手续费。通过这样做，他们帮助网络保持去中心化和高效。

与普通比特币交易相比：

* **链上交易** 直接发生在比特币区块链上。它们非常安全，但可能更慢且费用更高。
* **闪电网络交易** 在链下进行，允许支付更快完成且成本更低。

因此，闪电网络适合小额、日常支付，而链上交易通常用于大额转账或长期储存。

###### 例子 2

Mina 喜欢外出就餐，经常光顾她最喜欢的本地咖啡馆。面对众多支付方式，她不确定哪种最好。幸运的是，她已经了解了一些比特币和闪电网络的知识。经过比较，Mina 意识到使用闪电支付是最佳选择。

Mina 想买一杯咖啡，但用普通比特币交易有时会花费时间且手续费较高。于是，她决定使用闪电网络。

闪电网络让人们可以即时发送比特币且手续费极低。这使其非常适合像买咖啡这样的日常小额消费。

为了开始使用闪电网络，Mina 在手机上下载了一个闪电钱包。然后，她将一些比特币从普通比特币钱包转入闪电钱包。这一步使用的是区块链上的普通比特币交易。一旦资金进入她的闪电钱包，就可以在闪电网络上使用了。

现在 Mina 可以用闪电网络即时支付咖啡馆。支付发生在比特币主链之外，因此比普通链上交易更快、更便宜。


| 优势 | 闪电网络 | 传统银行系统 |
| --- | --- | --- |
| 速度 | 快 | 慢 |
| 透明度 | 透明 | 不透明 |
| 安全性 | 安全 | 易受攻击 |
| 交易手续费 | 低 | 高 |
| 金融包容性 | 高 | 有限 |
| 可扩展性 | 高 | 低 |
| 隐私性 | 高 | 中等 |
| 互操作性 | 高 | 低 |
| 合规性 | 中等 | 高 |
| 成本效益 | 高 | 中等 |


简单来说，链上交易是直接在比特币区块链上进行的，通常需要更多的时间和手续费。闪电网络交易则是在链下进行，能够实现快速且低成本的支付，同时仍然使用比特币。


| Visa公司 | 比特币链上 | 闪电网络 |
| --- | --- | --- |
| 每秒可处理65000笔交易。 | 每秒可处理7笔交易。 | 每秒可处理数百万笔交易。 |

###### 要点

1. 使用闪电钱包可以增强你收发真实聪（sats）的信心。
1. 注意单位。有些钱包允许用户发送比特币或聪（1比特币的1亿分之一）。
1. 闪电支付有时在路由过程中会卡住，尤其是大额支付。虽然这种情况有可能发生，但随着网络的成熟，这种用户体验已变得越来越少见。
