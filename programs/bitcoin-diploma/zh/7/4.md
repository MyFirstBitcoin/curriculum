# 7.4 发送和接收闪电网络交易

使用 Lightning 钱包后，使用比特币变得快捷、便宜且隐私性强，使得两个人之间的交易变得轻松。你可以快速地用比特币进行日常消费，比如买咖啡。

让我们来看几个 Lightning 网络实际应用的例子。

###### 例子 1

玛丽娅和伊芙各有 5 单位货币。玛丽娅想给伊芙转账 2 单位。付款通过杰夫传递，他帮助这笔款项在 Lightning 网络上传送。交易完成后，伊芙有 7 单位，玛丽娅有 3 单位。

杰夫帮助转发付款，但他无法窃取资金。Lightning 网络利用密码学确保只有指定的收款人才能收到付款。杰夫只是帮助付款在网络中流转。

这展示了 Lightning 网络的一个关键优势：人们可以快速转账，而无需信任像银行这样的中介。

像杰夫这样的节点运营者也可以通过帮助转发付款赚取少量手续费。通过这样做，他们帮助网络保持去中心化和高效。

与普通比特币交易相比：

* **链上交易** 直接在比特币区块链上进行。它们非常安全，但可能更慢且费用更高。
* **Lightning 交易** 在链下进行，允许付款更快完成，且成本更低。

因此，Lightning 适合小额、日常支付，而链上交易通常用于大额转账或长期储存。

###### 例子 2

米娜喜欢外出用餐，经常光顾她最喜欢的本地咖啡馆。面对众多支付方式，她不确定哪种最合适。幸运的是，她已经了解了一些关于比特币和 Lightning 网络的知识。经过比较，米娜发现使用 Lightning 支付方式是最佳选择。

米娜想买一杯咖啡，但用普通比特币交易有时会比较慢且手续费较高。于是，她决定使用 Lightning 网络。

Lightning 网络让人们可以即时发送比特币，手续费极低。这使得它非常适合像买咖啡这样的小额日常消费。

为了开始使用 Lightning，米娜在手机上下载了一个 Lightning 钱包。然后，她把一些比特币从普通比特币钱包转到 Lightning 钱包。这一步是在区块链上用普通比特币交易完成的。一旦资金进入她的 Lightning 钱包，就可以在 Lightning 网络上使用了。

现在米娜可以用 Lightning 立即支付咖啡馆。付款发生在比特币主链之外，因此比普通链上交易更快、更便宜。


| 优势 | Lightning 网络 | 传统银行系统 |
| --- | --- | --- |
| 速度 | 快 | 慢 |
| 透明度 | 透明 | 不透明 |
| 安全性 | 安全 | 易受攻击 |
| 交易手续费 | 低 | 高 |
| 金融包容性 | 高 | 有限 |
| 可扩展性 | 高 | 低 |
| 隐私性 | 高 | 中等 |
| 互操作性 | 高 | 低 |
| 合规性 | 中等 | 高 |
| 成本效益 | 高 | 中等 |


链上交易直接发生在比特币区块链上，可能需要更多时间和手续费。闪电网络交易则在链下进行，能够实现快速且低成本的支付，同时仍然使用比特币。


| Visa公司 | 比特币链上 | 闪电网络 |
| --- | --- | --- |
| 每秒可处理65,000笔交易。 | 每秒可处理7笔交易。 | 每秒可处理数百万笔交易。 |

###### 要点

1. 使用闪电钱包会增强你收发真实聪的信心。
1. 注意单位。有些钱包允许用户发送比特币或聪（1比特币的1亿分之一）。
1. 闪电支付有时在路由过程中会卡住，尤其是大额支付。虽然有可能发生，但随着网络的成熟，这种用户体验已变得越来越少见。
