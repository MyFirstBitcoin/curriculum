# 7.5 用比特币购买咖啡和杂货

你有没有想过，是否可以用比特币买你每天的咖啡或囤积日常杂货？其实你完全可以！现在有许多线上和线下的选择，让你可以用比特币支付。我们将探索其中的一些选项，以及帮助你找到本地商店、让你能花比特币的工具。

虽然用信用卡或应用程序支付对付款人来说似乎很简单易懂，但实际上支付处理过程非常复杂，涉及许多不同的中介方。


> **Note – 支付处理是如何运作的**
>
> 顾客 → 商家 → 支付网关 → 处理机构 → 卡组织 → 发卡银行 → 卡组织 → 商户银行 → 商家


每个中介都会收取费用，所以虽然看起来简单、快捷又便宜，但这些成本对小企业主来说很快就会累积起来，通常会超过价格的3%。更不用说还有货币兑换费了！

通过比特币和闪电网络，企业可以通过一个开放、安全、原生于互联网、无国界且抗审查的货币系统，从世界各地即时收款。

#### 线上

**BTCPay Server** 是一个开源支付处理器，让商家几乎无需技术知识就能接受比特币支付。它完全免费，不收取任何佣金。线上商家只需将 BTCPay 插件添加到自己的网站，就能无缝集成 BTCPay Server。由于 BTCPay Server 是一个开源项目，而不是公司，你在了解更多相关知识和计算机编程后，也可以为该项目做出贡献。请访问 [BTCPayServer.org](https://btcpayserver.org/) 获取更多关于如何将此支付系统用于你的线下或线上业务的信息。

##### BTCPay Server：有何不同？

* **免费且开源**：从免费到免费。MIT 许可证。无交易、订阅或处理费用。完全开源。支付是直接的点对点。
* **去中心化**：任何人都可以部署服务器。成为自托管的支付处理器，直接收款到你的钱包。你还可以帮助朋友或社区，为他们处理支付。一个 BTCPay Server 可以绑定无限数量的商店。
* **隐私，无中介**：受信任的第三方是安全漏洞。BTCPay 消除了这些中介。支付是点对点、直接的。数据不会被共享。无需 KYC/AML。
* **安全**：你的私钥永远不需要提供。非托管。BTCPay 只需要 xpubkeys（公钥）来生成发票。代码开源，可供安全审计员和开发者检查。
* **抗审查**：没有中心化的故障点。除了运行它的用户，没有人能控制它。你可以在自己的硬件上运行。

#### 线下

实体店也可以使用 BTCPay Server 来收款，或者他们也可以直接下载一个比特币钱包，用手机直接收款。

要查找你所在地区接受比特币的商家，请访问 [BTCMap.org](https://btcmap.org) 并搜索你的地区。BTCMap.org 是一个开源地图，接受比特币的商家可以在上面列出自己的店铺。此外，用户也可以添加新商家，甚至更新地图，确保列表上的商家仍然接受比特币。对于想要花比特币的人来说，这是一个非常强大的工具。

#### 过渡工具：代金券、礼品卡和支付卡

对于还未接受比特币的商家，你可以使用一种中介工具：礼品卡，来购买他们的产品或服务。

有些企业专注于用比特币买卖礼品卡。这意味着你可以用比特币换取你想购物的商店的礼品卡，然后直接在该商店消费。机票、酒店、游戏、SIM 卡……几乎所有东西都可以用比特币和礼品卡购买！

#### 循环经济

![ ](https://cdn.sanity.io/images/vje9ehw2/staging/b7074d4c1f4ba151124ba01f31db4eba6edac85e-190x58.svg)

一个**循环经济** 由参与者组成，他们决定尽可能相互支持，尽量在彼此之间买卖。例如，一个农民社区互相交换农产品，而不是去超市。

应用到比特币时，循环经济是通过支持接受比特币的本地商家和手艺人来建立的，这样所有参与者都能因比特币的优越属性而共同繁荣。


> **Note**
>
> 闪电网络让比特币循环经济能够在全球各地出现和繁荣，因为比特币交易几乎即时且手续费极低。


世界上第一个比特币循环经济诞生在荷兰阿纳姆。那时还没有闪电网络——但当时链上手续费非常低！

第二个是比特币海滩，位于萨尔瓦多的 El Zonte。它是第一个利用闪电网络的力量，为主要没有银行账户的社区提供用智能手机直接进行即时数字支付的地方！

如今，全球各地正在建立数百个循环经济，这些经济体由比特币、闪电网络和教育资源驱动。

在[BTCMap.org](https://btcmap.org/communities)，你还可以查找比特币社区，在那里你会遇到其他比特币用户，并找到接受比特币的商家。我们的一些老师和学生实际上已经在 BTCMap.org 上添加了商家和比特币循环经济——等你准备好了，你也可以这样做！
