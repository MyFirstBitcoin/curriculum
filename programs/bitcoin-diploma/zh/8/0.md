# 8.0 介绍

> 比特币并不是“无监管”；它是由算法进行监管，而不是由政府官僚机构监管。未被腐化。  
_安德烈亚斯·M·安东诺普洛斯_

在本模块中，我们将更深入地了解比特币的技术层面。我们用简单的语言解释保护协议安全的密码学原理，以及交易是如何运作的。有些概念可能看起来很技术性，但不用担心。许多人每天都在使用互联网，却并不完全了解其工作原理。

学习比特币的技术细节是一段漫长的旅程，并非每个人都需要走完。虽然我们鼓励持续学习，但本模块侧重于关键基础知识。

比特币网络是一个由许多计算机（称为节点）共同维护的交易记录。这个记录被称为比特币账本，是伪匿名的。它不包含姓名或年龄等个人信息，只记录交易数据和比特币地址。账本追踪自区块链诞生以来的每一笔交易。


> **Note – 比特币协议的机制**
>
> * 工作量证明
> * 加密时间戳
> * 难度调整
> * 点对点网络架构
> * 哈希函数与默克尔树
> * 公钥密码学
> * 区块奖励减半
