# 10.1 什么是中央银行数字货币（CBDC）？

中央银行数字货币（CBDC）是法定货币的数字版本。CBDC 遵循与法定货币相同的规则，即由中央权威机构（如政府）可以单方面扩大发行量，从而降低人们的购买力。然而，CBDC 还赋予政府全新的强大工具，可以控制全球人民如何使用这些货币。

根据人权基金会（HRF）的研究，全球有 134 个国家和货币联盟正在探索 CBDC，这些国家和联盟占全球 GDP 的 98%。而在 2020 年 5 月，这一数字仅为 35 个。目前，有 66 个国家处于探索的高级阶段——开发、试点或已推出。所有 G20 国家都在探索 CBDC，其中有 19 个国家已进入 CBDC 探索的高级阶段。

>
> 你可以在“人权基金会”的 CBDC 追踪器上查看你的国家是否正在试点 CBDC，网址为 [cbdctracker.hrf.org](https://cbdctracker.hrf.org/) 或 [cbdctracker.org](https://cbdctracker.org/)


那么，除了数字化之外，CBDC 与普通法币还有什么不同？关键在于，CBDC 不同于纸币或硬币形式的普通法币，它让政府能够数字化地监控和控制全球每一笔交易。这意味着，如果政府不喜欢你或你使用资金的方式，他们可以阻止某些交易，甚至冻结你的整个账户。

举个例子，假设你想给需要帮助的亲属汇款到另一个国家，但你的本国政府因为不同意那个国家的领导人而拒绝了你的交易。或者你去商店买自己喜欢的东西，但因为你在社交媒体上自由表达了观点，结果无法完成购买。

目前，流通中的大部分法币其实已经是数字形式——不同之处在于，现在是多家银行可以监控和审查交易，而且只限于通过它们账户的交易。尽管如此，上述那种审查的例子在许多国家已经发生并持续发生，虽然是由银行执行，但往往是应中央政府的要求。

然而，CBDC 让政府能够对其管辖范围内的资金使用拥有极大控制权，限制个人自由支配资金的能力。有些人认为，CBDC 可能让政府能够即时执行政策，无需人工干预。不再需要与多家银行协调，他们可以迅速追踪并阻断国内的资金流动。


| CBDC | Bitcoin |
| --- | --- |
| 无限供应 | 有限供应 |
| 中心化 | 去中心化 |
| 不透明的货币政策 | 透明的货币政策 |
| 封闭且需许可 | 开放且无需许可 |
| 有被没收的风险 | 无法被没收 |
| 侵犯隐私 | 注重隐私 |
| 支持审查 | 抗审查 |


CBDC 和 Bitcoin 都是数字货币，但除了这一点相似之外，它们代表了截然不同的货币形态和理念，因此会带来不同的结果。
