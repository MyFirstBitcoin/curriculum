# 3.3 中央银行数字货币

中央银行数字货币（CBDC）是法定货币的下一步发展。与传统的纸币、硬币和数字支付的组合不同，CBDC 是由政府发行、中央银行控制的完全数字化的法定货币形式。

想象一下你每天使用的货币，但没有任何实体形态——没有可以在口袋里叮当作响的硬币，也没有可以折叠的纸币。CBDC 的独特之处在于它为政府和中央银行提供了更高水平的控制和监控能力。通过 CBDC，相关部门能够前所未有地洞察金融交易，使他们更容易追踪、监管和限制资金流动。

政府和中央银行可以轻松调整 CBDC 的形式和供应量，操控利率，并以更高的精确度实施货币和财政政策工具。本质上，CBDC 为当局提供了一种更高效的方式来影响和管理他们的法定货币。

虽然 CBDC 似乎代表着法定货币的未来，但当前世界的货币体系实际上已经完全采用了纯粹的法币标准。法定货币不再与黄金挂钩，这导致货币供应量大幅扩张，而没有任何实际的限制。
