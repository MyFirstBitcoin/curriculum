# 3.3 中央银行数字货币

中央银行数字货币（CBDC）是法定货币的下一步发展。与由纸币、硬币和数字支付共同组成的传统货币不同，CBDC 是由政府发行、中央银行控制的完全数字化的法定货币形式。

想象一下你每天使用的货币，但完全没有实体存在——没有可以在口袋里叮当作响的硬币，也没有可以折叠的纸币。CBDC 的不同之处在于，它为政府和中央银行提供了更高程度的控制和监控能力。通过 CBDC，相关部门可以前所未有地掌握金融交易的透明度，使他们更容易追踪、监管和限制资金流动。

政府和中央银行可以轻松调整 CBDC 的形式和供应量，操控利率，并以更高的精确度实施货币和财政政策工具。本质上，CBDC 为当局影响和管理其法定货币提供了一种更高效的手段。

虽然 CBDC 看似是法定货币的未来，但当前世界的货币体系实际上已经完全采用了纯粹的法币标准。法定货币早已不再与黄金挂钩，这导致货币供应量大幅扩张，而没有任何实际的限制。
