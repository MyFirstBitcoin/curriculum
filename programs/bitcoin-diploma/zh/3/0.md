# 3.0 介绍

> 人类的历史就是货币贬值的历史。  
_米尔顿·弗里德曼_

在上一模块中，我们了解了货币是如何随着时间演变的，以及我们的货币体系如何从健全货币转变为不健全货币，塑造了我们今天所处的世界。本模块将进一步探讨这些发展如何导致了当今的法币体系，以及这个法币体系是如何运作的。

###### 那么，我们今天使用的法币体系是如何产生的呢？

要理解这一点，我们需要关注美元。如今，美元作为世界主要的储备货币，意味着许多国家在贸易、储蓄和金融稳定方面都依赖于它。正因如此，关于美元的决策会影响到全球各地的经济。

要理解你所在国家的货币是如何运作的，了解现代法币体系在美国的发展过程会很有帮助。
