# 比特币文凭

**比特币文凭**是My First Bitcoin的旗舰教育项目。

它提供**全面而系统的比特币入门课程**，旨在让学习者深入理解：

- 什么是比特币，
- 它如何运作，
- 为什么它很重要，
- 以及如何负责任地使用它。

该项目被全球各地的教育工作者、学生和合作组织所使用。

## 🎯 教育目标

完成比特币文凭课程后，学习者应能够：

- 解释比特币的核心概念和原则，
- 从高层次理解其技术基础，
- 安全地使用比特币进行自托管和交易，
- 批判性地评估关于比特币的常见误解和叙述。

课程重点在于**理解、自主权和长期思维**，而非投机或交易。

## 👥 目标受众

比特币文凭专为以下人群设计：

- 没有比特币基础知识的初学者，
- 学生和社区学习者，
- 教育工作者和培训师，
- 任何寻求扎实比特币概念基础的人。

不需要技术或金融背景。
