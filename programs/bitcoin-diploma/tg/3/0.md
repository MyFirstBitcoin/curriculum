# 3.0 Муқаддима

> Таърихи инсоният таърихи аз даст рафтани арзиши пул аст.  
_Милтон Фридман_

Мо дар модули гузашта дидем, ки чӣ гуна пул бо гузашти вақт тағйир ёфт ва низоми пулии мо аз пули устувор ба пули беасос гузашт, ки ҷаҳонеро, ки имрӯз зиндагӣ мекунем, шакл дод. Ин модул амиқтар мефаҳмонад, ки чӣ гуна ин рӯйдодҳо ба низоми фиати имрӯза оварда расонданд ва низоми фиат чӣ гуна кор мекунад.

###### Пас, низоми фиате, ки имрӯз истифода мебарем, чӣ гуна ба вуҷуд омад?

Барои фаҳмидани ин, бояд ба доллари ИМА назар андозем. Имрӯз доллар ҳамчун асъори асосии захиравии ҷаҳон хизмат мекунад, яъне бисёр кишварҳо барои тиҷорат, пасандоз ва суботи молиявӣ ба он такя мекунанд. Аз ин сабаб, қарорҳое, ки дар бораи доллари ИМА қабул мешаванд, ба иқтисодиёти тамоми ҷаҳон таъсир мерасонанд.

Барои фаҳмидани он, ки пул дар кишвари шумо чӣ гуна кор мекунад, фаҳмидани он муҳим аст, ки низоми фиати муосир дар Иёлоти Муттаҳида чӣ гуна ташаккул ёфт.
