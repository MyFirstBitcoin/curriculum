# 3.3 Асъори рақамии бонки марказӣ

Асъори рақамии бонки марказӣ (CBDC) қадами навбатии асъори фиатӣ мебошанд. Ба ҷои омезиши пулҳои қоғазӣ, тангаҳо ва пардохтҳои рақамӣ, CBDC шакли пурра рақамии асъори фиатӣ мебошанд, ки аз ҷониби ҳукуматҳо бароварда шуда, таҳти назорати бонкҳои марказӣ қарор доранд.

Тасаввур кунед, ки асъоре, ки ҳар рӯз истифода мебаред, дигар ҳеҷ гуна шакли ҷисмонӣ надорад — на тангае, ки дар ҷайбатон ҷингила кунад ва на пуле, ки қат кунед. Фарқи асосии CBDC дар сатҳи баланди назорат ва мониторинге аст, ки ба ҳукуматҳо ва бонкҳои марказӣ фароҳам меорад. Бо CBDC, мақомот имкони бесобиқаи дидани муомилоти молиявиро пайдо мекунанд, ки пайгирӣ, танзим ва маҳдуд кардани гардиши пулро осонтар мегардонад.

Ҳукуматҳо ва бонкҳои марказӣ метавонанд шакл ва ҳаҷми CBDC-ро ба осонӣ тағйир диҳанд, меъёри фоизро идора кунанд ва абзорҳои сиёсати пулӣ ва молиявиро бо дақиқии бештар истифода баранд. Дар асл, CBDC ба мақомот воситаи муассиртаре барои таъсир расонидан ва идора кардани асъори фиатии худ медиҳад.

Гарчанде CBDC ояндаи пули фиатӣ ба назар мерасад, низоми кунунии пулӣ дар ҷаҳон аллакай бар асоси стандарти поки фиат амал мекунад. Асъорҳои фиатӣ дигар ба тилло вобаста нестанд, ки ин боиси афзоиши назарраси ҳаҷми пул бе ягон маҳдудияти воқеӣ шудааст.
