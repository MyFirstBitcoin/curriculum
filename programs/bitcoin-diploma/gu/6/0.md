# 6.0 પરિચય

> કોઈ પણ વ્યક્તિ નર્ડ પૈસા કરતાં કેન્દ્રિય બેંકના પૈસા પર શા માટે વિશ્વાસ કરશે? નર્ડ્સે તમને ઇન્ટરનેટ આપ્યું. બેંકો તમને મહામંદી આપી.  
_Satoshi Nakamoto_

હવે આપણે સમજ્યા છીએ કે બિટકોઇન શું છે અને તેનો હેતુ શું છે, હવે તેને પ્રયોગમાં કેવી રીતે વાપરવું તે શીખવાનો સમય છે. આ મોડ્યુલમાં, અમે તમને બિટકોઇન મેળવવાની પ્રક્રિયા પગલાંવાર સમજાવશું, વિવિધ પ્રકારના વૉલેટ્સ વિશે જાણકારી આપશું, તમારો પોતાનો Bitcoin વૉલેટ કેવી રીતે સેટ કરવો તે શીખવડાવશું, અને નેટવર્ક પર બિટકોઇન ટ્રાન્ઝેક્શન મોકલવાની અને ટ્રેક કરવાની પ્રેક્ટિસ પણ કરાવશું. હવે તમારી સમજણને અમલમાં મૂકવાનો સમય આવ્યો છે!
