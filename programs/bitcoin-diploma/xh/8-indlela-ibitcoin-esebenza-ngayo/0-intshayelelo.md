# 8.0 Intshayelelo

> I-Bitcoin ayilawulwa "ngabantu abangekho mthethweni;" ilawulwa yialgorithm endaweni yokulawulwa ngoorhulumente. Ayigqwethwanga.  
_Andreas M. Antonopoulos_

Kule module, sijonga ngokusondeleyo kwicala lobugcisa le-Bitcoin. Sichaza ngendlela elula indlela i-cryptography ekhusele ngayo le protocol kunye nendlela ezisebenza ngayo iintengiselwano. Ezinye iingcinga zinokubonakala zinzima, kodwa ungakhathazeki. Abantu abaninzi basebenzisa i-intanethi yonke imihla bengaqondi ngokupheleleyo indlela esebenza ngayo.

Ukufunda icala lobugcisa le-Bitcoin luhambo olude olungafuneki ukuba wonke umntu aluthathe. Nangona sikhuthaza ukuqhubeka nokufunda, le module igxile kwiziseko eziphambili.

Umnatha we-Bitcoin yirekhodi esabelwana ngayo yeentengiselwano egcinwa kwiikhompyutha ezininzi ezibizwa ngokuba ngama-node. Le rekhodi, eyaziwa njenge-ledger ye-Bitcoin, ayichazi amagama abantu okanye iminyaka yabo, kuphela idatha yeentengiselwano kunye needilesi ze-Bitcoin. I-ledger ilandelela yonke intengiselwano ukusukela oko i-blockchain yaqala.

##### Iindlela zokusebenza kweProtocol ye-Bitcoin

* Ubungqina Bomsebenzi (Proof-of-Work)
* Iimpawu zexesha ezikhuselwe yi-cryptography
* Ulungiso lobunzima
* Ulwakhiwo lwenethiwekhi ye-Peer-to-Peer
* Imisebenzi ye-Hash kunye nemithi ye-Merkle
* I-Cryptography yeSitshixo sikaWonke-wonke
* Ukuncitshiswa kweSibonelelo seBlock
