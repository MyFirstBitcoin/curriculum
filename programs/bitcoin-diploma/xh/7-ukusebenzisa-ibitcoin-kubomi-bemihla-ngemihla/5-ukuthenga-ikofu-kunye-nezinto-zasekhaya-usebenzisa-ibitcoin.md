# 7.5 Ukuthenga Ikofu kunye Nezinto Zasekhaya usebenzisa iBitcoin

Ukhe wakhe wazibuza ukuba ungasebenzisa i-bitcoin ukuthenga indebe yakho yekofu yemihla ngemihla okanye ukuthenga izinto zokutya ekhaya? Kuyavela ukuba unako! Kukho iindlela ezininzi, kwi-intanethi nakwiivenkile zomzimba, ezikuvumela ukuba uhlawule nge-bitcoin. Siza kuphonononga ezinye zezo ndlela kunye nezixhobo eziza kukunceda ufumane iivenkile ezikufutshane ukuze ukwazi ukusebenzisa i-bitcoin yakho.

Nangona ukuhlawula ngekhadi letyala okanye nge-app kunokubonakala kulula kumntu ohlawulayo, inkqubo yokuhlawula inzima kakhulu kwaye ibandakanya amaqela amaninzi ahlukeneyo.


> **Note – Indlela Yokusebenza Kwenkqubo Yokuhlawula**
>
> Umthengi → Umrhwebi → Isango leNtlawulo → Umphathi weNtlawulo → Inethiwekhi yeKhadi → Ibhanki ekhupha amakhadi → Inethiwekhi yeKhadi → Ibhanki yomrhwebi → Umrhwebi


Umntu ngamnye ophakathi uthatha imali yenkonzo, ngoko ke, nangona kungabonakala kulula, kukhawuleza, kwaye kungabizi, ezi ndleko zinokukhawuleza zibe phezulu kumntu omncinci oshishino, zihlala zigqitha kwi-3% yexabiso. Kwaye asikabali neendleko zokutshintsha imali!

NgeBitcoin kunye neLightning Network, amashishini angafumana iintlawulo kwangoko avela kwihlabathi liphela ngokusebenzisa inkqubo yemali evulekileyo, ekhuselekileyo, eyenzelwe i-intanethi, engenamda, kwaye engavimbelwanga.

#### Kwi-Intanethi

**BTCPay Server** ngumphathi wentlawulo ovulekileyo onika abathengisi ithuba lokwamkela iintlawulo nge-bitcoin ngaphandle kolwazi olunzulu lobugcisa. Imahla ngokupheleleyo kwaye ayibizi naziphi na iikomishini. Amashishini akwi-intanethi angadibanisa i-BTCPay Server ngokulula ngokongeza i-plugin ye-BTCPay kwiwebhusayithi yawo. Kuba i-BTCPay Server yiprojekthi evulekileyo, hayi inkampani, unokunceda kule projekthi xa sele ufunde ngakumbi ngayo kunye nenkqubo yekhompyutha. Jonga [BTCPayServer.org](https://btcpayserver.org/) ukuze ufumane ulwazi olungakumbi malunga nendlela yokusebenzisa le nkqubo yokuhlawula kwishishini lakho elikwi-intanethi okanye elomzimba.

##### BTCPay Server: Yahluke Ngantoni?

* **Imahla kwaye ivulekile**: Yenziwe imahla ukuya kwimahla. Ilayisensi ye-MIT. Akukho ntlawulo yokuthengiselana, yokubhalisa okanye yokusebenza. Ivulekile ngokupheleleyo. Iintlawulo ziqhutywa ngqo, phakathi kwabantu ababini.
* **Isebenza ngokuzimeleyo**: Nabani na angamisa iseva yakhe. Yiba ngumphathi wentlawulo ozimeleyo kwaye ufumane iintlawulo ngqo kwi-wallet yakho. Nceda abahlobo bakho okanye uluntu lwakho kwaye uphathe iintlawulo zabo. Inani elingenamda leevenkile linokudityaniswa kwi-BTCPay Server enye.
* **Iimfihlo, Akukho mntu ophakathi**: Amaqela athembekileyo aphakathi ayingozi kwikhuseleko. I-BTCPay iyawasusa. Iintlawulo ziqhutywa phakathi kwabantu ababini, ngqo. Idatha ayabelwana ngayo. Akukho KYC/ALM.
* **Ikhuselekile**: Isitshixo sakho semfihlo asidingeki. Ayigcini mali. I-BTCPay ifuna kuphela ii-xpubkeys (isitshixo sikawonke-wonke) ukwenza i-invoice. Ikhowudi ivulekile kwaye ingajongwa ngabahlalutyi bokhuseleko kunye nabaqambi.
* **Ayivimbelwanga**: Akukho ndawo iphambili yokusilela. Akukho mntu uyilawulayo ngaphandle komsebenzisi oyisebenzisayo. Ungayiqhuba kwizixhobo zakho.

#### Ubuso ngobuso

Iivenkile zomzimba nazo zingasebenzisa i-BTCPay Server ukwamkela iintlawulo, okanye zingalanda nje i-wallet yeBitcoin kwaye zamkele iintlawulo ngqo kwifowuni yazo.

Ukufumana umrhwebi owamkela i-bitcoin kwindawo okuyo, yiya ku [BTCMap.org](https://btcmap.org) kwaye ukhangele ummandla wakho. I-BTCMap.org imephu evulekileyo apho abathengisi abamkela iBitcoin banokubhalisa amashishini abo. Kwaye, abasebenzisi banokongeza abathengisi abatsha kwaye bahlaziye imephu ukuqinisekisa ukuba abathengisi abakhankanyiweyo basamkela i-bitcoin. Sisixhobo esinamandla kubantu abafuna ukusebenzisa i-bitcoin yabo.

#### Izixhobo Zokutshintsha: Iivawutsha, Amakhadi Esipho, kunye Namakhadi Okuhlawula

Ukuthenga iimveliso okanye iinkonzo kumashishini angakamkeli i-bitcoin, kukho isixhobo esiphakathi ongasisebenzisa: amakhadi esipho.

Amanye amashishini agxile ekuthengeni nasekuthengiseni amakhadi esipho ngokutshintshiselana nge-bitcoin. Oko kuthetha ukuba unokufumana ikhadi lesipho kwivenkile ofuna ukuthenga kuyo ngokutshintshiselana nge-bitcoin, emva koko usebenzise ikhadi lesipho ngqo kwivenkile. Amatikiti eenqwelomoya, iihotele, imidlalo, amakhadi e-SIM... unokuthenga phantse nantoni na nge-bitcoin kunye namakhadi esipho!
