# 7.2 Diferentes tipos de monederos Lightning

Una billetera Lightning es similar a una billetera de Bitcoin en el sentido de que te permite enviar y recibir bitcoin. La diferencia clave es que funciona en la red Lightning, una segunda capa construida sobre Bitcoin. Al igual que las billeteras de Bitcoin, las billeteras Lightning tienen diferentes características que deben considerarse antes de elegir una.

#### Autocustodia vs Custodia

Las billeteras Lightning se pueden agrupar de muchas maneras, pero por simplicidad, las dividimos en dos tipos: autocustodia y custodia.  
Una billetera autocustodia significa que tú controlas tus claves. Una billetera custodia significa que otra persona las controla.  
Con una billetera custodia, puedes enviar y recibir pagos, pero dependes de un tercero y renuncias al control total de tus fondos por conveniencia. Esto puede ser aceptable para cantidades pequeñas, pero se recomienda usar una billetera autocustodia una vez que entiendas cómo funciona. Para lo que sigue, solo hablaremos de billeteras Lightning autocustodia.

#### Código abierto vs. Código cerrado

Las billeteras Lightning también pueden ser de código abierto o de código cerrado. Se prefieren las billeteras de código abierto porque su código es público, puede ser revisado por cualquiera y puede ser mejorado por la comunidad.
