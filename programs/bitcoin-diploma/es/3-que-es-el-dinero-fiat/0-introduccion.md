# 3.0 Introducción

> La historia de la humanidad es la historia del dinero perdiendo valor.  
_Milton Friedman_

En el módulo anterior vimos cómo el dinero evolucionó con el tiempo y cómo nuestro sistema monetario pasó de un dinero sólido a un dinero no sólido, dando forma al mundo en el que vivimos hoy. Este módulo profundiza en cómo estos acontecimientos condujeron al sistema fiat actual y cómo funciona ese sistema fiat.

###### Entonces, ¿cómo surgió el sistema fiat que usamos hoy?

Para entenderlo, necesitamos observar el dólar estadounidense. Hoy, el dólar funciona como la principal moneda de reserva del mundo, lo que significa que muchos países dependen de él para el comercio, el ahorro y la estabilidad financiera. Debido a esto, las decisiones sobre el dólar estadounidense afectan a las economías de todo el mundo.

Para entender cómo funciona el dinero en tu país, ayuda comprender cómo se desarrolló el sistema fiat moderno en Estados Unidos.
