# 16.2 Ask learners about the learning experience

Collect feedback that can improve delivery:

* Which explanation became clear through discussion or activity?
* Which section moved too quickly or slowly?
* Which term or translation was difficult?
* Which activity felt relevant locally?
* Where did technology or access create a barrier?
* Did any task create discomfort or pressure to disclose?
* Did practical work feel safe and purposeful?
* Which question remains unanswered?

Do not ask only whether learners “liked” the course. Look for evidence about clarity, participation, safety, transfer, and local usefulness.
