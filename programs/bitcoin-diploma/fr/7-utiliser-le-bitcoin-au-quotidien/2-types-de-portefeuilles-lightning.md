# 7.2 Types de portefeuilles Lightning

Un portefeuille Lightning s'apparente à un portefeuille Bitcoin dans la mesure où il permet d'envoyer et de recevoir des bitcoins. La principale différence réside dans le fait qu'il fonctionne sur le Lightning Network, une couche secondaire construite par-dessus le réseau Bitcoin. À l'instar des portefeuilles Bitcoin, les portefeuilles Lightning présentent différentes caractéristiques à prendre en compte avant d'en choisir un.

#### Gestion autonome ou gestion par un tiers

Les portefeuilles Lightning peuvent être classés de différentes manières, mais par souci de simplicité, nous les divisons en deux catégories : les portefeuilles auto-gérés et les portefeuilles gérés par un tiers.  
Un portefeuille auto-géré signifie que vous contrôlez vos clés. Un portefeuille géré par un tiers signifie que quelqu’un d’autre les contrôle.  
Avec un portefeuille de garde, vous pouvez envoyer et recevoir des paiements, mais vous dépendez d’un tiers et renoncez au contrôle total de vos fonds au profit d’une plus grande commodité. Cela peut convenir pour de petits montants, mais il est recommandé d’utiliser un portefeuille auto-géré une fois que vous en comprenez le fonctionnement. Dans la suite de cette section, nous nous concentrerons uniquement sur les portefeuilles Lightning autogérés.

#### Logiciels libres contre logiciels propriétaires

Les portefeuilles Lightning peuvent également être open source ou propriétaires. Les portefeuilles open source sont privilégiés car leur code est public, peut être examiné par n'importe qui et peut être amélioré par la communauté.
