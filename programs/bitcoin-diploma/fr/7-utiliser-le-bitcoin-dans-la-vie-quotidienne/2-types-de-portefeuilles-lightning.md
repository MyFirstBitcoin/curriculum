# 7.2 Types de portefeuilles Lightning

Un portefeuille Lightning est similaire à un portefeuille Bitcoin en ce qu'il vous permet d'envoyer et de recevoir des bitcoins. La principale différence est qu'il fonctionne sur le Lightning Network, une seconde couche construite au-dessus de Bitcoin. Comme les portefeuilles Bitcoin, les portefeuilles Lightning possèdent différentes fonctionnalités à prendre en compte avant d'en choisir un.

#### Auto-garde vs Garde par un tiers

Les portefeuilles Lightning peuvent être classés de plusieurs façons, mais pour simplifier, nous les divisons en deux types : auto-garde et garde par un tiers.  
Un portefeuille en auto-garde signifie que vous contrôlez vos clés. Un portefeuille en garde par un tiers signifie que quelqu'un d'autre les contrôle.  
Avec un portefeuille en garde par un tiers, vous pouvez envoyer et recevoir des paiements, mais vous dépendez d'un tiers et vous abandonnez le contrôle total de vos fonds pour plus de commodité. Cela peut convenir pour de petites sommes, mais il est recommandé d'utiliser un portefeuille en auto-garde une fois que vous comprenez son fonctionnement. Pour le reste de cette section, nous nous concentrerons uniquement sur les portefeuilles Lightning en auto-garde.

#### Open source vs Source fermée

Les portefeuilles Lightning peuvent également être open source ou à source fermée. Les portefeuilles open source sont préférés car leur code est public, peut être examiné par tous et peut être amélioré par la communauté.
