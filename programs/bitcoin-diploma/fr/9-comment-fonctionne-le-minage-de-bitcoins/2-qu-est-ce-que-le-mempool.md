# 9.2 Qu'est-ce que le mempool ?

Le **mempool**, abréviation de « memory pool », s'apparente à une salle d'attente pour les transactions Bitcoin. Lorsque vous envoyez des bitcoins, votre transaction est d'abord diffusée sur le réseau, puis placée dans le mempool.

C'est un peu comme faire la queue dans un restaurant. Votre nom est inscrit sur une liste, et vous attendez qu'une table se libère. De la même manière, votre transaction reste en attente dans le mempool jusqu'à ce qu'un mineur l'intègre dans un bloc.

Les nœuds Bitcoin vérifient chaque nouvelle transaction afin de s'assurer qu'elle est valide et que les bitcoins dépensés n'ont pas déjà été utilisés. Si la transaction est valide, elle reste dans le mempool jusqu'à ce qu'elle soit confirmée.

Les mineurs sélectionnent des transactions dans le mempool et les intègrent dans de nouveaux blocs. En général, ce sont les transactions dont les frais sont les plus élevés qui sont choisies en premier.

Une fois qu'une transaction est incluse dans un bloc, elle est validée et enregistrée de manière définitive sur la blockchain Bitcoin.

###### Points clés

1. **Mempool** fait référence à la liste des transactions non confirmées gérée par chaque nœud Bitcoin, et non à un service ou une plateforme spécifique.
1. Il ne s'agit pas d'un mempool unique et universel. Mempool.space est l'un parmi tant d'autres.
1. [Mempool.space](https://mempool.space) est un logiciel libre, réputé pour être un explorateur de blocs visuel et facile à utiliser. Il fournit des données en temps réel sur les transactions non confirmées, les taux de frais et d'autres activités du réseau.

###### Conseil aux étudiants

Mempool.space ne se contente pas de visualiser les blocs. Découvrez d'autres aspects de l'écosystème Bitcoin : par exemple, le réseau Lightning, le minage, le taux de hachage, les pools et les « lunettes » d'espace de bloc.
