# 7.2 Soorten Lightning-wallets

Een Lightning-portemonnee lijkt op een Bitcoin-portemonnee in die zin dat je er bitcoin mee kunt versturen en ontvangen. Het belangrijkste verschil is dat deze werkt op het Lightning Network, een tweede laag die bovenop Bitcoin is gebouwd. Net als bij Bitcoin-portemonnees zijn er bij Lightning-portemonnees verschillende functies waarmee je rekening moet houden voordat je er een kiest.

#### Zelfbeheer versus beheer door een derde partij

Lightning-wallets kunnen op allerlei manieren worden ingedeeld, maar voor het gemak verdelen we ze in twee soorten: wallets waarbij je zelf de controle hebt en wallets waarbij een derde partij de controle heeft.  
Bij een wallet waarbij je zelf de controle hebt, beheer je je sleutels zelf. Bij een wallet waarbij een derde partij de controle heeft, beheert iemand anders je sleutels.  
Met een bewaarde portemonnee kun je betalingen versturen en ontvangen, maar je bent afhankelijk van een derde partij en geeft de volledige controle over je geld uit handen voor het gemak. Dit kan prima zijn voor kleine bedragen, maar het gebruik van een zelfbeheerde portemonnee wordt aanbevolen zodra je begrijpt hoe deze werkt. In de rest van dit hoofdstuk richten we ons uitsluitend op Lightning-wallets met eigen beheer.

#### Open source versus closed source

Lightning-wallets kunnen zowel open source als closed source zijn. Open-source wallets hebben de voorkeur omdat hun code openbaar is, door iedereen kan worden gecontroleerd en door de gemeenschap kan worden verbeterd.
