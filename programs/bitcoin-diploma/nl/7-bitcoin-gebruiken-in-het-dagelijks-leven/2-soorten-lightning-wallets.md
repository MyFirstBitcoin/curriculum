# 7.2 Soorten Lightning-wallets

Een Lightning-wallet lijkt op een Bitcoin-wallet doordat je er bitcoin mee kunt versturen en ontvangen. Het belangrijkste verschil is dat het werkt op het Lightning Network, een tweede laag bovenop Bitcoin. Net als Bitcoin-wallets hebben Lightning-wallets verschillende functies om te overwegen voordat je er een kiest.

#### Zelfbeheer versus Beheer door derden

Lightning-wallets kunnen op veel manieren worden ingedeeld, maar voor de eenvoud verdelen we ze in twee typen: zelfbeheer en beheer door derden.  
Een wallet met zelfbeheer betekent dat jij de sleutels beheert. Bij een wallet met beheer door derden beheert iemand anders ze.  
Met een wallet die door derden wordt beheerd, kun je betalingen versturen en ontvangen, maar ben je afhankelijk van een derde partij en geef je het volledige beheer over je geld op voor het gemak. Dit kan prima zijn voor kleine bedragen, maar zodra je begrijpt hoe het werkt, wordt het aanbevolen om een wallet met zelfbeheer te gebruiken. In de rest van deze sectie richten we ons alleen op Lightning-wallets met zelfbeheer.

#### Open source versus Gesloten bron

Lightning-wallets kunnen ook open source of gesloten bron zijn. Open-source wallets hebben de voorkeur omdat hun code openbaar is, door iedereen kan worden gecontroleerd en door de gemeenschap kan worden verbeterd.
