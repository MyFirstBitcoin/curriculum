# 7.2 Soorten Lightning-wallets

Een Lightning-wallet lijkt op een Bitcoin-wallet omdat je er bitcoin mee kunt versturen en ontvangen. Het belangrijkste verschil is dat het werkt op het Lightning Network, een tweede laag bovenop Bitcoin. Net als Bitcoin-wallets hebben Lightning-wallets verschillende functies waar je op moet letten voordat je er een kiest.

#### Zelfbeheer versus beheer door derden

Lightning-wallets kunnen op verschillende manieren worden ingedeeld, maar voor de eenvoud verdelen we ze in twee typen: zelfbeheer en beheer door derden.  
Bij een zelfbeheerde wallet beheer je zelf je sleutels. Bij een wallet die door derden wordt beheerd, beheert iemand anders ze.  
Met een wallet die door derden wordt beheerd, kun je betalingen versturen en ontvangen, maar ben je afhankelijk van een derde partij en geef je het volledige beheer over je geld op voor het gemak. Dit kan prima zijn voor kleine bedragen, maar zodra je begrijpt hoe het werkt, wordt het aanbevolen om een zelfbeheerde wallet te gebruiken. In de rest van deze sectie richten we ons alleen op zelfbeheerde Lightning-wallets.

#### Open source versus gesloten broncode

Lightning-wallets kunnen ook open source of gesloten broncode zijn. Open-source wallets hebben de voorkeur omdat hun code openbaar is, door iedereen kan worden gecontroleerd en door de gemeenschap kan worden verbeterd.
