# 比特币入门

比特币入门是一条从货币基础知识到比特币是什么以及人们如何使用它的简短线性路径。

它旨在让学习者清晰了解：

- 为什么货币很重要，
- 什么是货币（以及可能出现什么问题），
- 比特币从高层次来看是什么，
- 使用方式和后续步骤如何融入初学者的学习旅程。

教育工作者和自主学习者可以将其作为深入学习更完整课程（如[比特币文凭](https://github.com/MyFirstBitcoin/curriculum/tree/main/programs/bitcoin-diploma/zh)）之前的简洁入门。

## 🎯 教育目标

完成比特币入门课程后，学习者应能够：

- 解释为什么货币是一种影响日常决策的共同理念，
- 用简单的术语描述货币，并识别法币系统常见的失效模式，
- 概括比特币的用途及其与"只是另一个应用"的区别，
- 概述人们通常如何负责任地开始使用比特币，
- 在继续学习的过程中，找出合理的后续问题。

重点在于清晰和好奇心，而非交易、价格预测或投机。

## 👥 目标受众

比特币入门专为以下人群设计：

- 想要简短、系统概述的新手，
- 时间有限的学习小组、课堂和社区课程，
- 任何在深入学习更长课程之前想要单一叙事弧的人。

不需要技术或金融背景。
