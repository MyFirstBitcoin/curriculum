# ¿Cómo se usa Bitcoin?

Una billetera de Bitcoin es simplemente una aplicación que te permite enviar, recibir y administrar tu bitcoin. Lo más importante que debes entender antes de elegir una es la custodia.

###### ¿Quién realmente tiene tu bitcoin?

![](https://cdn.sanity.io/images/vje9ehw2/staging/0b3a21664386a27441afee165ab5b3078d5627ed-1377x768.svg)

Con una **billetera de autocustodia**, tienes el control total.

Cuando la configuras, genera una **frase semilla:** una secuencia de 12 o 24 palabras comunes en un orden específico. Esta frase es tu respaldo, de la cual se derivan las llaves privadas de tu billetera. Cualquiera que la tenga puede restaurar tu billetera y controlar tus fondos.



Escríbela en papel y guárdala en un lugar seguro, completamente fuera de línea. Nunca le tomes una foto, la envíes por correo electrónico ni la guardes digitalmente. Recuerda: quien tenga esas palabras tiene acceso a tu bitcoin, y si las pierdes sin respaldo, tu bitcoin se pierde para siempre.

Con una **billetera de custodia**, una empresa guarda tu bitcoin en tu nombre, como un banco.

La configuración es más sencilla y no necesitas administrar una frase semilla, lo que hace que estas billeteras sean una buena opción para montos pequeños y gastos diarios. El inconveniente es que confías tus fondos a esa empresa, y si congelan cuentas, son hackeados o cierran, podrías perder el acceso.

Una frase útil en el mundo de Bitcoin: **si no son tus llaves, no son tus monedas.**

Aquí tienes algunas opciones de billeteras que puedes probar tú mismo. Como siempre, haz tu propia investigación y entiende lo que haces antes de depositar fondos que no estés dispuesto a perder.

##### Billeteras de autocustodia


| Nombre | Descripción | Fuente |
| --- | --- | --- |
| Bluewallet | Una billetera móvil potente pero sencilla, con configuración rápida, una interfaz intuitiva para Enviar/Recibir y seguimiento solo de visualización para billeteras de hardware, manteniendo tu Bitcoin en cadena separado y seguro. | bluewallet.io |
| Blockstream Wallet | Una billetera enfocada en la seguridad con configuración singlesig sencilla, interfaz intuitiva para Enviar/Recibir y emparejamiento fluido con Jade, compatible tanto con Bitcoin como con la red Liquid. | blockstream.com/app |
| Bull Bitcoin Wallet | Una billetera enfocada en la privacidad, solo para Bitcoin, con un sistema dual de billetera para ahorro y gasto, datos de comisiones en tiempo real y soporte de solo visualización para billeteras de hardware. | wallet.bullbitcoin.com |
| Aqua Wallet | Una "superapp" de Bitcoin para gastos diarios, con una interfaz simplificada para Bitcoin, Lightning y Liquid. | aqua.net |
| Manna | Una billetera moderna todo en uno con una interfaz de autocustodia limpia para Bitcoin, Lightning y Liquid, además de chat cifrado y un mapa BTC integrado para encontrar lugares que aceptan sats. | mannabitcoin.com |


##### Billeteras de custodia


| Nombre | Descripción | Fuente |
| --- | --- | --- |
| Blink | Una billetera de Bitcoin de nivel inicial para uso diario con pagos Lightning de custodia instantáneos y un mapa de comercios integrado para encontrar tiendas locales que aceptan Bitcoin. | blink.sv |
| Wallet of Satoshi | Una de las billeteras Lightning más simples del mundo, con configuración de custodia instantánea, interfaz simplificada de Escanear para Pagar y una dirección Lightning personal para transacciones cotidianas fáciles. | walletofsatoshi.com |


Para comenzar, cualquiera de las billeteras de autocustodia mencionadas son opciones bien valoradas que te guían en el proceso de creación de la frase semilla.

Para pagos pequeños y cotidianos, Blink y Wallet of Satoshi son billeteras Lightning de custodia. Son rápidas, económicas y fáciles para principiantes.

La **Red Lightning** es una capa construida sobre la cadena de bloques de Bitcoin, diseñada para transacciones rápidas y de bajo costo, ideal para el uso cotidiano.
