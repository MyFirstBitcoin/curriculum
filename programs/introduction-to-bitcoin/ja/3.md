# 私たちのお金の何が問題なのか？

インフレーションという言葉を聞くと、多くの人は物価が上がることだと思いがちです。

それは事実ですが、それはあくまで症状にすぎません。

その根本的な原因はもっと本質的なものです。お金は今や無制限に作り出すことができ、その仕組みをコントロールしているのはごく一部の人々です。

何が価値を生み出すのか、考えてみてください。

モナリザの原画がどんなコピーよりも高価なのは、見た目が優れているからではなく、それが唯一無二だからです。希少性が価値を生み出します。同じ理屈がお金にも当てはまります。

**あるものの単位が多くなればなるほど、それぞれの価値は下がります。**

アメリカドルは1913年以降、購買力の96%以上を失いました。

1940年に19セントだったチーズバーガーは、今では2.50ドル以上します。これはチーズバーガーが良くなったからではなく、1ドルの価値が昔よりも下がったからです。

あなたの貯金も、給料も、購買力も、あなたが何かしたからではなく、この仕組みの設計によって、静かに時間とともに減っていっています。

**これは、My First Bitcoinが解決しようとした問題です。**
