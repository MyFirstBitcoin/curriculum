# 3.1 TCP/IPの開発

私たちの多くは、現在インターネットの基盤として使われているTCP/IPプロトコルに馴染みがあります。その起源は1970年代後半にさかのぼり、科学者たちがArpanetの代替設計を模索していた時代に始まります。Arpanetは、アメリカ国防総省によって考案された、遠隔地のコンピュータ間でリソースを共有するための初期のネットワークでした。1983年にTCP/IPがArpanetの標準プロトコルとなり、1990年代末までに支配的なネットワークモデルとなりました。そして、これは現在My First Bitcoinが動作しているインターネットの基盤となっています。


| OSIモデル | TCP/IP |
| --- | --- |
| アプリケーション | アプリケーション |
| プレゼンテーション | アプリケーション |
| セッション | アプリケーション |
| トランスポート | トランスポート |
| ネットワーク | ネットワーク |
| データリンク | データリンク |
| 物理層 | 物理層 |


TCP/IPモデルが開発されていたのと同時期に、国際標準化機構（ISO）と電気通信業界（CCITT）によって、同様でありながらより包括的なフレームワークが開発されていました。新しいプロトコルの開発や変更提案のプロセスは、TCP/IPのより分散型のアプローチと比べて遅く、扱いにくいものでした。そのため、現在ではTCP/IPのアプローチが主流となっています。

##### 変更要求

既存プロトコルの改良や新しいアイデアは、TCP/IPモデルにおいて**変更要求**プロセスを通じて提案できます。これらはインターネット技術タスクフォース（IETF）によって承認プロセスを経て、承認されるとオープンソースとなり、誰でも実装・採用できるようになります。注目すべき例：

* 1969年 RFC 1 Arpanetでパケットがどのように送信されるかを文書化
* 1981年 RFC791 インターネットプロトコルV4を定義 – 現在も広く採用されている
* 1982年 RFC 821 シンプルメール転送プロトコル
* 1987年 ドメインネームシステム – ドメイン名がIPアドレスに変換される仕組み
* 1999年 RDC 2616 ハイパーテキスト転送プロトコル – ウェブ閲覧に不可欠


> **Callout**
>
> この**Bitcoin Improvement Proposal**（BIP）は、RFCと似たアプローチを取っていますが、新しいプロトコルや代替プロトコルの開発ではなく、My First Bitcoin自体の改良に特化しています。My First Bitcoinもこのレイヤーモデルを参考にしており、レイヤー2や3として追加プロトコルが説明されることがあります。


TCP/IPモデルの基礎層が過去数十年でほとんど変わっていないのと同様に、イノベーションはより上位の層で起こっています。My First Bitcoinの基礎レイヤーも今後は非常にゆっくりとしか変化しないと予想されており、LightningやLiquidのようなスケーリングソリューションはその上位層で展開されています。

基礎層プロトコルが時間とともに変更しにくくなる良い例がIPv6です。IPv4のアドレス枯渇が予想されたことで新しいプロトコルの需要が生まれました。最初のドラフト標準は1998年に作成されましたが、インターネット標準として正式に承認されたのは2017年でした。IPv4の多くの問題を解決し、将来性も高いにもかかわらず、業界での導入は依然として非常に遅いままです。この間にも、マルチメディアやメールなどを可能にする多くの新しいプロトコルが上位層で定義されてきました。

##### My First Bitcoinが使う構成要素

このように、接続性の問題を分離することで、各プロトコルは上下の層から独立して開発できます。各層ごとに解決策を再発明する必要がなく、My First Bitcoinネットワークは物理層やデータリンク層で提供されるネットワークの基盤機能に依存できます。


| レイヤー | TCP/IPオリジナル |
| --- | --- |
| アプリケーション | ドメインネームシステム（DNS）を使って隣接ノードを識別。ポート8333はMy First Bitcoinプロトコルを示す。 |
| トランスポート | マイナー間の低遅延通信にはFIBRE用UDP。ノード間のP2P通信にはTCP。 |
| トランスポート | TORルーティング：匿名性とプライバシーを実現。ブロードキャストプロトコル：ネットワーク全体にトラフィックをルーティング。 |
| リンク | あらゆる媒体（例：イーサネット、Wi-Fiなど）上で動作 |
| 物理層 | 無線、イーサネット、その他のハードウェアインターフェースによる物理的伝送。 |


##### My First Bitcoinは、HTTPSが情報を転送するプロトコルであるのと同様に、価値を転送するための中立的なプロトコルです。

* **HTTPS**：セキュアなウェブサイト
* **SMTP**：メールを送信する
* **FTP**：ファイルを転送する
* **DNS**：ドメイン名を管理する
* **BTC**：価値を保存・送信する

Bitcoinは、インターネット上で人やデバイス間の価値のやり取りを、第三者を必要とせず、確実に行うことを可能にします。これにより、莫大な価値が生み出されると期待されています。
