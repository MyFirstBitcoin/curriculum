# 1.4 જોખમો, અસરકારકતા અને ભવિષ્યની સંભાવનાઓનું મૂલ્યાંકન

આગામી કસરતમાં, તમારા વર્ગના ટ્યુટર દ્વારા સુવિધિત, આપણે એક ઉદાહરણ સંસ્થા પસંદ કરીશું, કદાચ એવી કે જે અહીં હાજર વિદ્યાર્થી માટે સંબંધિત હોય, અને વિભાગો 1.1-1.3 માં દર્શાવેલી પદ્ધતિને પ્રયોગમાં અનુસરીશું.

અહીં કેટલીક પ્રશ્નો છે જે તમે પૂછો છો:

* મારા ઉત્પાદનો / સેવાઓ માટેનું બજાર ભવિષ્યમાં કેવું દેખાશે?
* જ્યારે દેવું ઓછું ઉપલબ્ધ હોય અથવા વધુ ખર્ચાળ હોય એવા વિશ્વમાં અમારી બેલેન્સ શીટ / ફંડિંગ સ્ત્રોતો કેવી રીતે બદલાઈ શકે?
* નીચેના ગ્રાહક અથવા સપ્લાયર બજારોમાં ફેરફારથી મારી સંસ્થાને અસર થશે કે નહીં:
  * બાંધકામ / રિયલ એસ્ટેટ
  * ઊર્જા / ગરમી
  * નાણાકીય સેવાઓ
  * સરકારી ખરીદી / સેવાઓ
  * કચરો વ્યવસ્થાપન
