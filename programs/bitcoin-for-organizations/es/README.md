# Bitcoin para Organizaciones

**Bitcoin para Organizaciones** es un programa educativo diseñado para ayudar a las organizaciones a comprender Bitcoin en un **contexto estratégico, operativo y educativo**.

Un objetivo resumido del programa sería:

**Proporcionar a las organizaciones una base para comprender por qué Bitcoin debe incluirse en el pensamiento estratégico, el análisis de riesgos y la planificación a largo plazo.**

⚠️ Recomendamos encarecidamente que todos los lectores comiencen con el **Módulo 1: Bitcoin y Gestión de Riesgos** antes de explorar el resto del programa.

La perspectiva basada en el riesgo introducida en el primer módulo sirve como base para los módulos que le siguen.

## 👥 Público objetivo

Este programa está destinado a:

- líderes senior y tomadores de decisiones
- educadores y gestores de programas
- organizaciones sin fines de lucro y orientadas a una misión
- equipos de finanzas, operaciones y tecnología
- profesionales técnicos y no técnicos que buscan una comprensión seria de Bitcoin

## Temas del programa

A lo largo del programa, varios temas aparecen de forma recurrente:

- Bitcoin como un asunto estratégico, no solo técnico o financiero
- la gestión de riesgos como punto de partida para el análisis organizacional
- la relación entre Bitcoin, la energía y la infraestructura
- la relevancia de Bitcoin para diferentes sectores y funciones internas
- el pensamiento a largo plazo ante el cambio tecnológico
- el valor de los datos públicos y los sistemas abiertos para el análisis económico

## Notas

- Este programa tiene un carácter educativo.
- Está destinado a apoyar la comprensión, la discusión y el pensamiento crítico.
- No debe interpretarse como asesoramiento financiero, legal, fiscal o de inversión.
