# 1.4 การประเมินความเสี่ยง ผลกระทบ และสถานการณ์ในอนาคต

ในแบบฝึกหัดต่อไปนี้ ซึ่งจะมีผู้สอนในชั้นเรียนของคุณเป็นผู้นำ เราจะเลือกองค์กรตัวอย่าง อาจจะเป็นองค์กรที่เกี่ยวข้องกับนักเรียนคนใดคนหนึ่งในห้อง และนำวิธีการที่อธิบายไว้ในหัวข้อ 1.1-1.3 มาปฏิบัติจริง

นี่คือตัวอย่างคำถามที่คุณอาจจะถามได้:

* ตลาดสำหรับสินค้า / บริการของฉันในอนาคตจะมีลักษณะอย่างไร?
* งบดุล / แหล่งเงินทุนของเราจะเปลี่ยนแปลงอย่างไรในโลกที่การกู้ยืมเงินเข้าถึงได้ยากขึ้น / มีต้นทุนสูงขึ้น?
* องค์กรของฉันจะได้รับผลกระทบจากการเปลี่ยนแปลงในตลาดลูกค้าหรือซัพพลายเออร์ต่อไปนี้หรือไม่:
  * การก่อสร้าง / อสังหาริมทรัพย์
  * พลังงาน / การทำความร้อน
  * บริการทางการเงิน
  * การจัดซื้อจัดจ้าง / บริการภาครัฐ
  * การจัดการขยะ
