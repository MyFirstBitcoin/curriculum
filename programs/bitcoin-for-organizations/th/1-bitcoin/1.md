# 1.1 การระบุความเสี่ยง

> การวางแผนเชิงกลยุทธ์ไม่ใช่การคิดเชิงกลยุทธ์ ที่จริงแล้ว การวางแผนเชิงกลยุทธ์มักจะทำลายการคิดเชิงกลยุทธ์ ทำให้ผู้บริหารสับสนระหว่างวิสัยทัศน์ที่แท้จริงกับการจัดการตัวเลข_เฮนรี่ มินซ์เบิร์ก_

บุคคลที่เหมาะสมที่สุดในการระบุความเสี่ยงคือผู้ที่มีความรู้ลึกซึ้งเกี่ยวกับองค์กรของตนเองและวัตถุประสงค์ ผลิตภัณฑ์ ตลาด ช่องทาง และกลยุทธ์ปัจจุบันขององค์กรเหล่านั้น คนเหล่านี้ต้องศึกษาบิตคอยน์มาแล้ว เข้าใจอย่างดีว่าทำไมมันถึงมีอยู่ มันเข้ามาแก้ปัญหาอะไร และทำไมมันถึงมีมูลค่า

ดังนั้น ขั้นตอนแรกคือการพัฒนาบุคลากรให้มีความรู้ที่จำเป็น หากยังไม่มีอยู่แล้ว ห้องสมุด MPB สำหรับโมดูลองค์กรนี้ และโดยเฉพาะโมดูลนี้ ถูกสร้างขึ้นมาเพื่อช่วยตอบสนองความต้องการด้านการฝึกอบรมและพัฒนานี้โดยเฉพาะ

เมื่อมีทักษะพร้อมแล้ว ขั้นตอนถัดไปคือพิจารณาว่าจะระบุความเสี่ยงที่เกี่ยวข้องกับการเปลี่ยนแปลงที่อาจเปลี่ยนแปลงองค์กรได้อย่างไร ความเสี่ยงที่เกิดขึ้นใหม่คือ “ความเสี่ยงที่กำลังพัฒนาในพื้นที่และรูปแบบที่ความรู้ที่มีอยู่ยังอ่อนแอ”1

ผู้จัดการความเสี่ยงที่ดีควรให้ความสำคัญกับผลลัพธ์ที่มีผลกระทบสูง แม้โอกาสจะ (ถูกมองว่า) ต่ำก็ตาม ดังนั้น แทนที่จะเริ่มจากปัจจุบัน ให้ลองจินตนาการถึงอนาคตปลายทางที่บิตคอยน์กลายเป็นแหล่งเก็บมูลค่าระดับโลก สื่อกลางในการแลกเปลี่ยน และอาจเป็นหน่วยวัดมูลค่าด้วย ในสถานการณ์นี้ ลองพิจารณาคำถามต่อไปนี้:

* การค้าขายในตลาดภายในประเทศของคุณตอนนี้เปรียบเทียบกับการค้าระดับโลกอย่างไร? มีอะไรเปลี่ยนแปลงบ้าง?
* ภูมิรัฐศาสตร์เปลี่ยนแปลงไปอย่างไร?
* ตลาด/ผลิตภัณฑ์ใดที่มีมูลค่าเพิ่มขึ้น? และตลาด/ผลิตภัณฑ์ใดที่หดตัวลง?
* องค์กรใดที่ทำได้ดีเป็นพิเศษ? และองค์กรใดที่ทำได้ไม่ดี?
* ประเทศใดที่แข็งแกร่งขึ้น? และประเทศใดที่อ่อนแอลง?
* การกระจายความมั่งคั่งในหมู่ผู้คนเปลี่ยนแปลงไปหรือไม่? ในรูปแบบใดบ้าง?
* บทบาทของสถาบันการเงินเปลี่ยนไปอย่างไร? แล้วรัฐบาลล่ะ?

จากนั้นลองย้อนกลับจากจุดปลายทางเพื่อพิจารณาว่าการเปลี่ยนแปลงจากปัจจุบันไปสู่อนาคตนี้เกิดขึ้นได้อย่างไร ลองพิจารณาหัวข้อต่าง ๆ เช่น:

* ลำดับของเหตุการณ์
* ความราบรื่นหรือความฉับพลัน/ความผันผวนของการเปลี่ยนแปลงระหว่างทาง
* บทบาทของรัฐชาติ ตลาด องค์กร และบุคคลในการก่อให้เกิดการเปลี่ยนแปลง
* จุดข้อมูลใหม่ ๆ ที่หากมองย้อนกลับไปจะเป็นร่องรอยของการเดินทาง

สุดท้าย แปลงข้อสังเกตจากแบบฝึกหัดข้างต้นให้เป็นความเสี่ยงที่เกี่ยวข้องกับองค์กรของคุณ พิจารณาปัจจัยลำดับที่สองและสาม มีแนวโน้มว่าข้อสังเกตแต่ละข้ออาจมีความเสี่ยงหลายประการ ความเสี่ยงเหล่านี้อาจเป็นทั้งภัยคุกคามและโอกาส


| การดำเนินการ | วิธีการ |
| --- | --- |
| ระบุความเสี่ยง | การทดลองทางความคิด |
| ระบุผลกระทบ | ประยุกต์ใช้กับองค์กรของคุณ |
| ประเมินผลกระทบ | ตารางความน่าจะเป็น / ขนาดผลกระทบ |
| จัดการผลกระทบ | การยอมรับ การบรรเทา การยอมรับ/การใช้ประโยชน์ |
| ติดตามความเสี่ยง | ทบทวนและปรับฐานข้อมูลเป็นระยะ |



> **Dark – ตัวอย่าง**
>
> * ความเสี่ยงที่บิตคอยน์กลายเป็นสินทรัพย์สำรองคลังหลักระดับโลก
> * ความเสี่ยงที่เครือข่าย Bitcoin กลายเป็นชั้นการชำระบัญชีสำหรับการค้าบนอินเทอร์เน็ต
> * ความเสี่ยงที่อัตราดอกเบี้ยเงินกู้ในอนาคตอาจสูงขึ้นอย่างมีนัยสำคัญ
> * ความเสี่ยงที่โครงสร้างประชากรของความมั่งคั่งและรายได้อาจเปลี่ยนแปลง
> * ความเสี่ยงที่ทุกคนบนโลก (หรือในตลาดเป้าหมายของคุณ) ใช้สกุลเงินเดียวกัน
