# 1.4 அபாயங்கள், பாதிப்புகள் மற்றும் எதிர்கால நிகழ்வுகளை மதிப்பீடு செய்தல்

பின்வரும் பயிற்சியில், உங்கள் வகுப்பு ஆசானால் வழிநடத்தப்படுவதால், நாம் ஒரு உதாரண நிறுவனத்தை தேர்ந்தெடுப்போம், அது இங்கு உள்ள மாணவர்களுக்கு தொடர்புடையதாக இருக்கலாம், மற்றும் பிரிவுகள் 1.1-1.3-ல் விவரிக்கப்பட்ட முறையை நடைமுறையில் பின்பற்றுவோம்.

நீங்கள் கேட்கக்கூடிய சில கேள்விகள் இவை:

* என் தயாரிப்புகள் / சேவைகளுக்கான சந்தை எதிர்காலத்தில் எப்படி இருக்கும்?
* கடன் குறைவாகக் கிடைக்கும் அல்லது அதிக செலவில் கிடைக்கும் உலகில், எங்கள் சமநிலைப் பத்திரம் / நிதி ஆதாரங்கள் எவ்வாறு மாறக்கூடும்?
* பின்வரும் வாடிக்கையாளர் அல்லது வழங்குநர் சந்தைகளில் மாற்றங்கள் ஏற்பட்டால் என் நிறுவனம் பாதிக்கப்படுமா:
  * கட்டிடம் / நிலம் மற்றும் வீடு
  * ஆற்றல் / வெப்பம்
  * நிதி சேவைகள்
  * அரசு கொள்முதல் / சேவைகள்
  * கழிவுகள் மேலாண்மை
