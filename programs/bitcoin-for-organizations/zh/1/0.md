# 1.0 介绍

> 前瞻性扫描让你通过观察当下所蕴含的片段，得以一窥未来。  
_罗杰·斯皮茨_

想象一下你在1995年，做着你（或你的父母）当时的工作，但拥有现在的知识。事后诸葛地看，当时你的工作、你的组织或你的市场因互联网的即将兴起面临了哪些风险？是否既有需要规避的威胁，也有可以把握的机遇？或者假设你当时在百视达工作。如果你拥有现在的认知，并且你是上市公司的高级管理人员，那么如果你没有将互联网兴起的风险纳入你们组织的风险登记册，你就失职于作为股东资金托管人的受托责任。

互联网在1995年是一个新兴风险，就像今天的比特币一样。到1995年，互联网在社会讨论中已被广泛认知；它并不是科技圈的秘密。然而，几乎没有企业真正理解或应用它，除了新兴的互联网初创公司外，几乎没有人努力去了解它，甚至很少有人将其作为风险加以监控。

就像1995年的互联网一样，比特币如今也被广泛认知，但除了主要在比特币经济中运营的企业外，其他企业对其了解和应用都很有限。到1995年，互联网已经从20世纪60年代的起源，通过不断增加新的协议层，发展到足以点燃其爆炸性增长的可用性水平。

自2009年诞生以来，比特币也以类似的方式不断演进，逐步提升可用性并简化复杂性。正如互联网一样，比特币的用户数量也在缓慢增长（[https://bitcoinmagazine.com/markets/an-objective-look-at-bitcoin-adoption](https://bitcoinmagazine.com/markets/an-objective-look-at-bitcoin-adoption)），与此同时这些技术改进也在持续发生。和互联网一样，我们无法预知哪一次改进会成为引爆大规模采用的火花，只有事后才能知晓，但我们已经有了2022年及以后的数据，显示出“当下所蕴含的片段”（罗杰·斯皮茨）。
