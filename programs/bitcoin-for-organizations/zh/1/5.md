# 1.5 缓解措施与机遇

识别风险和评估影响的目的是让您的组织能够采取行动，以减轻威胁或利用机遇，如果分析支持这样的行动。

* 接受 / 监控
* 缓解
* 拥抱 / 利用

通过参考影响表中单元格的颜色，有助于优先排序。当某一影响为红色时，应优先于其他具有相似或更长时间框架的影响采取行动，绿色框的影响更适合接受和监控。

但要注意只监控而不采取行动的诱惑，因为这可能意味着未来某一时刻会有很多问题同时爆发。

避免损失厌恶。损失厌恶是一种认知偏见，表明对个人而言，失去的痛苦在心理上是获得的快乐的两倍。请将同等精力用于识别和利用机遇，而不仅仅是规避威胁。

避免过于果断。您可以为互斥的结果做好准备，这可以成为一种有用的风险管理策略。

在本节中，我们强调了一些通用的行动组，帮助您将分析转化为行动。此列表并非详尽无遗，而是旨在帮助您入门。


> **Light – 损益策略**
>
> * 保护现有收入和市场份额
>   * 减少对受不利影响市场的暴露
>   * 将增长重点放在有望受益的市场
> * 降低运营成本并提升效率
>   * 吸引并留住最佳人才
>   * 降低支付（尤其是国际支付）的成本和复杂性
> * 创新新产品、新渠道和新市场
>   * 识别增长渠道和市场
>   * 锁定新的、增长中的客户群体
>   * 与新客户群沟通，并为其创造产品和服务
>   * 审视竞争对手和新进入者的行动，考虑他们的优势和劣势。



> **Light – 资产负债表策略**
>
> * 从资产负债表中挖掘价值
>   * 减少对资本成本以下表现不佳资产的暴露，同时不降低资本韧性
> * 提升ESG报告指标
>   * 阅读KPMG美国发布的这份报告，了解如何通过参与比特币提升您未来的ESG评分
>   * [https://kpmg.com/us/en/articles/2023/bitcoin-role-esg-imperative.html](https://kpmg.com/us/en/articles/2023/bitcoin-role-esg-imperative.html)
> * 降低股权风险
>   * 对资产负债表进行足够重组，以便能够对相关的长期风险进行保险。
