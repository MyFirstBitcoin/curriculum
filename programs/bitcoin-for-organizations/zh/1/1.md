# 1.1 识别风险

> 战略规划并不等同于战略思考。事实上，战略规划常常破坏战略思考，使管理者将真正的愿景与数字操作混淆。  
_亨利·明茨伯格_

最适合识别风险的人，是那些对其组织及其既定目标、产品、市场、渠道和当前战略有深入了解的人。这些人还必须研究过比特币，对其存在的原因、要解决的问题以及其为何获得价值有良好的理解。

因此，第一步是培养具备必要知识的人才，如果目前还没有的话。本组织模块的MPB知识库，尤其是本模块，正是为满足这一培训和发展需求而专门创建的。

一旦具备了相关技能，下一步就是考虑在整体上可能带来变革性变化的情况下，如何最好地识别风险。新兴风险是“在知识体系薄弱的领域和方式中不断演变的风险”。

优秀的风险管理者应关注那些后果严重的结果，即使其发生的可能性（被认为）较低。因此，不要从现在出发，而是要设想一个未来的终点——比特币已成为全球价值储存手段、交换媒介，甚至可能成为记账单位。在这种情景下，思考如下问题：

* 你本国市场的贸易现状与全球贸易相比如何？发生了哪些变化？
* 地缘政治发生了哪些变化？
* 哪些市场/产品的价值增长了？哪些则萎缩了？
* 哪些组织表现相对较好？哪些表现较差？
* 哪些国家变得更强大？哪些则变得更弱？
* 人们之间的财富分配发生了变化吗？有哪些方面发生了变化？
* 金融机构的角色发生了哪些变化？政府呢？

然后尝试从终点倒推，思考从现在到未来这一情景的转变是如何展开的。可以考虑如下主题：

* 事件发生的顺序
* 中间变化的平稳性或突发性/波动性
* 国家、市场、组织、个人在变革中的作用
* 回顾来看，哪些新出现的数据点会成为这段历程的足迹

最后，将上述练习中的观察转化为与你的组织相关的风险。要考虑二阶和三阶因素。每一项观察很可能都包含若干风险。这些风险既可能是威胁，也可能是机遇。


| 行动 | 方法 |
| --- | --- |
| 识别风险 | 思想实验 |
| 识别影响 | 应用于你的组织 |
| 评估影响 | 可能性/影响程度表 |
| 管理影响 | 接受、缓解、拥抱/利用 |
| 监控风险 | 定期回顾与重置 |



> **Info – 示例**
>
> * 比特币成为主要的全球国库储备资产的风险
> * 比特币网络成为基于互联网的商业结算层的风险
> * 未来信贷价格可能大幅上升的风险
> * 财富和收入结构可能发生变化的风险
> * 地球上所有人（或你的目标市场）都使用同一种货币的风险
