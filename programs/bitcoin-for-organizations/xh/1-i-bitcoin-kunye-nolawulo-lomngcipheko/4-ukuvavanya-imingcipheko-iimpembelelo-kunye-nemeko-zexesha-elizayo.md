# 1.4 Ukuvavanya Imingcipheko, Iimpembelelo, kunye neMeko zeXesha elizayo

Kulo msebenzi ulandelayo, oza kuncediswa ngutitshala wakho, siza kukhetha umbutho umzekelo, mhlawumbi lowo unxulumene nomfundi okhoyo, size sisebenzise indlela echazwe kwiindawo 1.1-1.3 ngokwenziwa.

Nazi ezinye zeemibuzo onokuyibuza:

* Imarike yeemveliso / iinkonzo zam iza kujonga njani kwixesha elizayo?
* Ingaba ibhalansi yethu / imithombo yemali ingatshintsha njani kwihlabathi apho ityala lingafumaneki lula / libiza kakhulu?
* Ngaba umbutho wam unokuchaphazeleka ngotshintsho kwiimarike zabathengi okanye zababoneleli zilandelayo:
  * Ukwakhiwa / izindlu nomhlaba
  * Amandla / ukufudumeza
  * Iinkonzo zezezimali
  * Ukuthengwa / iinkonzo ngurhulumente
  * Ulawulo lwenkunkuma
