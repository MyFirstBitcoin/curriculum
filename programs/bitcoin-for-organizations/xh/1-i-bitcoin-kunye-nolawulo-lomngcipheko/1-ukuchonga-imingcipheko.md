# 1.1 Ukuchonga imingcipheko

> Ulungiselelo lwesicwangciso asilotyalo-mali lwengcinga yesicwangciso. Enyanisweni, ulungiselelo lwesicwangciso luhlala lonakalisa ingcinga yesicwangciso, lwenza abaphathi badide umbono wokwenene nokudlala ngenani._Henry Mintzberg_

Abantu abona balungileyo ekuchongeni imingcipheko ngabo abanolwazi olunzulu ngombutho wabo kunye neenjongo zawo ezichaziweyo, iimveliso, iimarike, imijelo kunye nesicwangciso sangoku. Aba bantu kufuneka babe bafundile ngeBitcoin, baqonde kakuhle ukuba kutheni ikhona, yeyiphi ingxaki ezama ukuyisombulula, kwaye kutheni ifumene ixabiso.

Ngoko ke, inyathelo lokuqala kukuphuhlisa abantu abanobuchule obufunekayo ukuba abakho sele bekhona. Le thala leencwadi leMPB leemodyuli zemibutho, kunye nale modyuli ngokukodwa, zenziwe ngokukodwa ukunceda ukuhlangabezana nalo mfuno yoqeqesho nophuhliso.

Xa izakhono sele zikhona, inyathelo elilandelayo kukuqwalasela indlela engcono yokuchonga imingcipheko xa inxulumene notshintsho olunokutshintsha ngokupheleleyo. Umngcipheko ophumayo 'ngumngcipheko ophuhlayo kwiindawo kunye neendlela apho ulwazi olukhoyo lusezantsi'.

Umphathi womngcipheko olungileyo kufuneka agxile kwiziphumo apho isiphumo siphezulu, nokuba amathuba okuba yenzeke aphantsi (kucingwa njalo). Ke, endaweni yokuqala ngoku, qala ngokucinga ngexesha elizayo apho iBitcoin sele ibe yindawo yokugcina ixabiso yehlabathi, indlela yokutshintshiselana kunye nokuba mhlawumbi ibe yinye yemilinganiselo yemali. Kulo meko, qwalasela imibuzo enje:

* Ngaba urhwebo kwimarike yakho yasekhaya luhluke njani kurhwebo lwehlabathi ngoku? Yintoni etshintshileyo?
* Ngaba imeko yezopolitiko yehlabathi itshintshile njani?
* Zeziphi iimarike/iimveliso ezonyuke amaxabiso? Zeziphi ezithotywe?
* Zeziphi iiorganizations ezenze kakuhle? Zeziphi ezenze kakubi?
* Zeziphi amazwe aphumelele ngakumbi? Zeziphi aphulukene namandla?
* Ngaba ulwahlulo lobutyebi phakathi kwabantu lutshintshile? Njani?
* Indima yeziko lezemali itshintshile njani? Kwaye urhulumente?

Emva koko zama ukubuyela umva ukusuka kwelo xesha lokugqibela ucinge ngendlela utshintsho olusuka ngoku ukuya kwelo xesha lwenzeka ngayo. Qwalasela imixholo enje:

* Ulandelelwano lweziganeko
* Ukugudeka okanye ukungazinzanga/ukuguquguquka kotshintsho oluphakathi
* Indima karhulumente, imarike, umbutho, kunye nomntu ngamnye ekubangeleni utshintsho
* Iidatha eziphumayo eziza kubonakala emva kwexesha njengemikhondo yohambo

Ekugqibeleni, guqulela izimvo ezivela kulo msebenzi ungentla zibe yimingcipheko efanelekileyo kumbutho wakho. Qwalasela izinto zesibini nezithathu ezichaphazelekayo. Kusenokwenzeka ukuba isichazi ngasinye sinemingeni emininzi. Imingcipheko inokuba zizoyikiso okanye amathuba.


| Intshukumo | Indlela |
| --- | --- |
| Chonga Imingcipheko | Uvavanyo lwengcinga |
| Chonga Iziphumo | Ukusetyenziswa kumbutho wakho |
| Vavanya Iziphumo | Iitafile zamathuba / ubukhulu |
| Lawula Iziphumo | Ukwamkelwa, ukunciphisa, ukwamkela/ukuxhamla |
| Jonga Imingcipheko | Uphengululo rhoqo kunye nokuhlaziya |



> **Info – Imizekelo**
>
> * Umngcipheko wokuba iBitcoin iba yeyona mali iphambili, igcinwe kwiingxowa-mali zehlabathi
> * Umngcipheko wokuba inethiwekhi yeBitcoin iba linqanaba lokuhlala kwezorhwebo kwi-intanethi
> * Umngcipheko wokuba ixabiso lemali-mboleko linokunyuka kakhulu kwixesha elizayo
> * Umngcipheko wokuba ulwahlulo lobutyebi kunye nengeniso lungatshintsha
> * Umngcipheko wokuba wonke umntu eMhlabeni (okanye kwimarike ojolise kuyo) usebenzisa imali enye
