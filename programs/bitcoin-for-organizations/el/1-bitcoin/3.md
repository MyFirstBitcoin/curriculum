# 1.3 Αξιολόγηση επιπτώσεων

Η χρήση ενός πίνακα όπως το παρακάτω παράδειγμα μπορεί να βοηθήσει στην αξιολόγηση των οργανωτικών επιπτώσεων από την υλοποίηση ενός κινδύνου.

![Evaluate Impacts using a Table](https://cdn.sanity.io/images/vje9ehw2/staging/7282d9e334ba9f810fdfa9d0244466bae86e77fb-492x221.svg)

_Λάβετε υπόψη την πιθανότητα σε διαφορετικά χρονικά διαστήματα (π.χ. 0-2, 3-5, 6-10, 10+ έτη)_

Τα δύο στοιχεία που πρέπει να ληφθούν υπόψη είναι η πιθανότητα υλοποίησης του κινδύνου και το μέγεθος της επίπτωσης στον οργανισμό. Και οι δύο αυτοί παράγοντες επηρεάζονται συνήθως από το χρονικό διάστημα που εξετάζεται, οπότε αξίζει να δημιουργηθεί ένας πίνακας για κάθε επίπτωση που έχει εντοπιστεί σε μια σειρά από διαφορετικά χρονικά διαστήματα.

Αυτοί οι τρεις παράγοντες σχετίζονται σε κάποιο βαθμό μεταξύ τους, για παράδειγμα, η πιθανότητα μιας άμεσης αλλαγής μεγάλης κλίμακας είναι μάλλον πολύ χαμηλή, αλλά σε μεγαλύτερο χρονικό διάστημα ή με μικρότερη ένταση μπορεί να είναι αρκετά υψηλή.

Ο χρωματισμός των κελιών στον πίνακα παρέχει έναν τρόπο για να βοηθήσει στην ιεράρχηση των ενεργειών, όπως καλύπτεται στην Ενότητα 3.5.

Είναι σημαντικό να σημειωθεί ότι αυτή η άσκηση πρέπει να είναι διαρκής. Καθώς το αβέβαιο μέλλον μετατρέπεται σε γνωστό παρελθόν, οι πιθανότητες, τα μεγέθη και τα μελλοντικά χρονικά διαστήματα θα αλλάζουν και θα εξελίσσονται. Όταν προκύπτουν νέα δεδομένα, επανεξετάστε τα προηγούμενα συμπεράσματά σας.



#### 1.3.1 Πιθανότητα

> Η διοίκηση είναι, πάνω απ' όλα, μια πρακτική όπου η τέχνη, η επιστήμη και η τεχνική συναντιούνται  
_Henry Mintzberg_

Ποια θεωρείτε ότι είναι η πιθανότητα υλοποίησης του κινδύνου, που οδηγεί στην επίπτωση, στο χρονικό διάστημα που εξετάζεται; Ποιο θα ήταν το επίπεδο του μεγέθους της επίπτωσης;

Δεν υπάρχουν «σωστές» απαντήσεις εδώ· μόνο διαφορετικές εκτιμήσεις βασισμένες σε ατομικές και οργανωτικές ερμηνείες των επιπτώσεων κάθε γεγονότος. Η ποικιλία στις συζητήσεις μπορεί να βοηθήσει στη βελτίωση των εκτιμήσεων με βάση την αρχή «ρωτήστε το κοινό», αν και οι απόψεις θα πρέπει να σταθμίζονται ανάλογα με τις σχετικές δεξιότητες και γνώσεις.

#### 1.3.2 Μέγεθος

Το μέγεθος κάθε επίπτωσης είναι πιθανό να αυξάνεται όσο μεγαλώνει το χρονικό διάστημα αναφοράς. Αυτό σημαίνει ότι είναι πιο πιθανό να πρέπει να ληφθούν μέτρα όσο πιο μακροπρόθεσμη είναι η προοπτική. Η μέτρηση των μεγεθών σε διαφορετικά χρονικά διαστήματα δίνει τη δυνατότητα να ιεραρχηθούν οι ενέργειες για όλους τους κινδύνους.

#### 1.3.3 Χρονικό διάστημα

Κατά μέσο όρο, για μια δεδομένη πιθανότητα και μέγεθος, όσο μικρότερο είναι το χρονικό διάστημα τόσο μεγαλύτερη προτεραιότητα πρέπει να δοθεί στη λήψη μέτρων.
