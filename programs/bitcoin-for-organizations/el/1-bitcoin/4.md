# 1.4 Αξιολόγηση Κινδύνων, Επιπτώσεων και Μελλοντικών Σεναρίων

Στην ακόλουθη άσκηση, με τη διευκόλυνση του δασκάλου σας, θα επιλέξουμε έναν παράδειγμα οργανισμό, ίσως κάποιον που σχετίζεται με έναν από τους παρόντες μαθητές, και θα εφαρμόσουμε στην πράξη τη μέθοδο που περιγράφεται στις ενότητες 1.1-1.3.

Ακολουθούν μερικές ερωτήσεις που μπορείτε να κάνετε:

* Πώς θα μοιάζει η αγορά για τα προϊόντα / τις υπηρεσίες μου στο μέλλον;
* Πώς θα μπορούσε να αλλάξει ο ισολογισμός μας / οι πηγές χρηματοδότησης σε έναν κόσμο όπου το χρέος είναι λιγότερο προσβάσιμο / πιο ακριβό;
* Θα επηρεαζόταν ο οργανισμός μου από αλλαγές στις ακόλουθες αγορές πελατών ή προμηθευτών:
  * Κατασκευές / ακίνητα
  * Ενέργεια / θέρμανση
  * Χρηματοοικονομικές υπηρεσίες
  * Κρατικές προμήθειες / υπηρεσίες
  * Διαχείριση απορριμμάτων
